# 纯仿真速度与加速度匹配对照

2026-10-23。保持1:1 XY映射、原固定3m×3m活动区、四边50cm缓冲。
不启动实车，不刷固件，不改Tenda/ESP32、原矩形程序或已有操作台。

## 结果与推荐

同步性问题的主要限制之一是运动能力不匹配，而不只是位姿处理延迟。
原0.20m/s、0.08m/s²从零升到限速就要2.5秒；只提速度而不匹配加减速会更差。
本次扫描找到两个**独立SIM ONLY**档位：

| 用途 | 平面合速度上限 | 平面合加速度上限 | 结论 |
| --- | ---: | ---: | --- |
| 最小平顺手势档 | 0.50m/s | 1.20m/s² | 峰值0.30～0.50m/s平顺手势已接近本模型的性能平台 |
| 扩展手势推荐档 | 0.70m/s | 2.00m/s² | 对峰值0.75m/s的平顺往返也明显改善，更适合下一轮真实Sign→仿真对比 |

两者都不是“实车已支持”。没有向现有操作台/实车配置自动应用；现有4W20许可未放宽。
杆Z/yaw不映射到车的平移/转动，车仍保持会话启动朝向。

## 受控消融：速度与加速度必须一起匹配

同一个峰值0.50m/s、峰值加速度0.833m/s²的平顺往返，输入完全相同：

| 参数（m/s；m/s²） | 同时刻XY误差RMS | 说明 |
| --- | ---: | --- |
| 0.20；0.08 | 25.98cm | 原限制 |
| 0.70；0.08 | 31.55cm | 只提速度，仍长期受加速度限制，反而更差 |
| 0.20；1.20 | 15.14cm | 只提加速度，仍追不上杆的速度 |
| 0.50；1.20 | 4.95cm | 两者匹配，改善约81% |
| 0.70；2.00 | 4.94cm | 对这一平顺动作再加大参数几乎不再改善 |

原限制在该动作约99.5%的控制周期触及正常加速度限制；0.50/1.20档约0.7%。
这只是模型下的因果对照，不是电机真实加速度测量。

## 扩展推荐档：0.70m/s、2.00m/s²

基准模型为速度一阶滞后0.12秒，前向/横向增益0.98/0.88，**不是本车辨识结果**。
所有误差均未时间平移对齐，不通过平移曲线隐藏延迟。

| 同输入轨迹 | 原档RMS | 推荐档RMS | 推荐档P95 |
| --- | ---: | ---: | ---: |
| 峰值0.30m/s平顺往返 | 21.79cm | 2.97cm | 4.20cm |
| 峰值0.50m/s平顺往返 | 25.98cm | 4.94cm | 6.98cm |
| 峰值0.75m/s较快往返 | 26.18cm | 7.33cm | 10.61cm |
| 约0.40m/s圆周动作 | 36.26cm | 6.15cm | 8.57cm |
| 真实记录1，中心回放 | 38.53cm | 10.80cm | 24.78cm |
| 真实记录2，中心回放 | 33.28cm | 2.88cm | 7.11cm |
| 真实记录3，中心回放 | 18.02cm | 6.41cm | 13.92cm |

0.50m/s平顺往返的换向延迟中位数约1.43秒→0.16秒。
0.75m/s较快往返在最小档RMS仍为13.81cm，扩展档降到7.33cm，
因此不把最小档说成能覆盖所有自然较快手势。

三段真实记录RMS分别改善约72%、91%、64%，但仍有快速突变未完全跟上。
真实记录1包含约1.4m/s的短时快速动作；推荐档的P95仍约25cm，不能宣称无延迟同步。
考虑静止会稀释误差，额外统计仅杆移动时的RMS，推荐档三段分别约14.20、3.67、9.31cm。

原角落起点两段另行回放：目标限幅比例保持约86%、97%，与参数无关；
中心回放没有目标限幅。软件车起点平移不移动围栏、不改变比例，也不缩小杆原始动作。

## 参数不能替代真实执行器响应

对扩展档另做了执行器模型敏感性检查，均未意外停机：

| 模型滞后；前向/横向增益 | 0.50m/s动作RMS | 0.75m/s动作RMS | 0.40m/s圆周RMS |
| --- | ---: | ---: | ---: |
| 0.04s；1.00/1.00 | 2.13cm | 3.27cm | 2.36cm |
| 0.12s；0.98/0.88 | 4.94cm | 7.33cm | 6.15cm |
| 0.25s；0.85/0.75 | 9.83cm | 13.31cm | 12.23cm |

说明：更高限速不一定继续改善平顺动作，执行器滞后和横向响应也会成为瓶颈。
扫描中没有任何一组在基准模型下让全部三种普通平顺动作均达到RMS≤5cm，圆周动作仍约6cm。
该探索性5cm目标没有达成，未通过修改算法/弱化保护来掩盖。

推荐是工程筛选而不是新的用户验收标准：最小档要求普通动作RMS≤7cm、P95≤10cm、
换向中位数≤250ms，且RMS距扫描最优不超过10%；三段中心真实回放各改善至少50%。
扩展档额外要求0.75m/s挑战RMS≤8cm、P95≤12cm、换向中位数≤250ms，选择满足条件的最小速度/加速度组合。

## 验证范围与保护

- 扫描25组参数×9条轨迹=225次完整运行；均无意外停机，输出与参考的速度/加速度限制、固定足迹围栏保持。
  **不代表225组同步性都达标**，原档的高误差也原样保留。
- 新增158项纯仿真回归通过，覆盖原档、最小档、扩展档及模型上界。
  较高档的故障注入在模型车输出超过0.30m/s后进行，不只在低速检查。
- 27类故障包括：杆/车位姿丢失与重放、反馈/租约/命令中断、源/owner冲突、超速/加速度/参考跳变、
  车体跳变/越界/抬起/倾斜、执行器故障、急停、时钟异常和会话超时等。
  零输出均在注入后240ms内出现；这是虚拟时钟测试边界，不是实车完全停稳时延。
- 数据恢复不会自动运动；释放使能、显式确认/重新准备、新使能边沿后才可再次跟随。
  重新使能重新取锚点，不追赶旧目标。此前现场手动恢复仍尚未现场完成，不据此冒充通过。
- 原候选84项回归通过。原连续伺服、Supervisor、FinalGate、4W20固件及矩形保护清单哈希未变化。
- 不运行ROS签名输出链、不打开设备/网络、不测电流、温升、制动、Vicon曝光到车轮延迟。
  松键后的模型惯性位移不是实车停车距离；四边50cm缓冲也未因此被认证为高速安全停车余量。
