# 4W20：独立0.20m/s首档，不是400RPM全范围固件

2026-10-23用户确认先0.20m/s，再考虑后续更高速档的停车余量、电流和温升。
本版将已使用过的35% PWM功率包络保留在STM32内，电脑端和STM32均限制
平移合速度0.20m/s、偏航0.10rad/s；不能仅改电脑参数开放更高速。
400RPM/80% PWM的4WGD候选完全保留，未刷入。

## 本版包络与保护

- 35% PWM、起动≤30%、800cps/s轮速目标斜坡；不重调原前馈/PI。
- 每轮目标≤1700cps且≤100RPM，轮缘≤0.30m/s，以容纳0.20m/s对角平移及偏航修正。
  100RPM是首档轮速保护包络，不是400RPM最终档，也不是实车已达到转速的结论。
- 原始编码器反馈超过120RPM触发超速故障；量化/过渡余量与目标上限分开。
- 保留600ms MCU断令、150s MCU绝对额度、120s电脑会话、200ms定位/反馈新鲜度、
  100ms签名指令期限、150ms操作员租约、堵转/反向证据/换向过零、CCR与实际授予方向校验。
- 松键/遮挡/失联停车、显式重新准备、不自动恢复运动，全部沿用。
- 独立4W20/156字节v1身份；旧4WGC或全4WGD包不能伪装本版。
- 私有信道做向零量化，避免0.20m/s边缘斜向指令逐轴四舍五入后误超MCU合速度上限。

这里没有测得停车距离、电流或温升，没有将上述项目写成合格，也没有新增硬件电流保护。
保留固定几何围栏及原0.20m车体余量，并不等于证明该余量适合任意故障下的停车。
本版只用于明确授权的首档受限验收；后续更高速必须单独处理上述未完成项目。

## 隔离与兼容性

原矩形、ESP32、网络配置、原4WGC源码/镜像和全4WGD源码/镜像均未修改。
4W20重用4WGC连续全向轮控及共同缩放运动学，只增加独立限值与身份。
**旧操作台/旧矩形入口会拒绝4W20身份，不能继续用原启动命令。**
“程序文件未改”不等于在新身份下未经适配也能运行旧矩形；要复用旧入口可恢复完整备份/原4WGC。

配套ROS包为`mecanum_wand_stage020_control`与`mecanum_wand_stage020_hardware`，
域96、命名空间`/wand_stage020_acceptance`，HMAC密钥独立；物理UDP端口独占锁不变。
2倍XY映射、忽略杆Z/姿态、2×2m名义中心活动区、每侧额外0.50m杆输入范围、
大目标引导与限幅、实际反馈时钟恢复均复用既有实现。

真实入口默认在创建Node/socket之前要求新的现场空旷/立即断电确认。
`stage020_policy`明确记录测停/电流/温升DEFERRED，不把原4WGD审核字段偷改为true。
候选生成器及检查脚本不运行ROS节点，不发送UDP，不刷写。
