# 自动检查、自动准备、单击空格入口

此独立主机候选只优化启动流程和窗口尺寸，不改变4WS8/ESP32固件、运动控制、安全门控、位移映射或原矩形程序。

## 使用流程

运行现有命令 `bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_demo_120s_toggle_eventio.sh`。
启动检查窗口与跟随窗口均默认1280×720（最小1000×640）。
用户仍须逐项勾选三个现场条件；程序不能替用户确认场地或断电人员。
文件、Tenda、Vicon/Sign/car01、位置和朝向检查通过且确认有效后，自动打开跟随窗口。
窗口获得焦点、Sign拿稳无遮挡、真实停稳和时钟/新鲜反馈等条件持续满足后，自动请求一次准备。
准备只进入ARMED，不转轮，不捕获运动原点；无需额外点“准备”。
看到“准备就绪”后，轻按并松开一次空格才启动本轮。提前按键不会被记住或稍后补启动。
准备后拿起、调整Sign仍不运动，位移原点按原版在真正使能时捕获。
再次按空格、Esc或停止按钮停车；切出窗口、遮挡、通信/定位故障、围栏等原有保护仍停车；松键本身不停车。
120秒从真正使能开始计时，不从检查或准备开始；结束或故障后不会自动重试、续跑或自动清除故障。

保留0.70m/s、0.80m/s²、1:1映射，以及最新已确认的前0.5/后1.5/左0.5/右0.4米区域和四边50厘米缓冲。
本轮没有重新扩大围栏，不是早期3×3米配置。

## 离线发布

`prepare.py --output <全新输出目录>`：核对父版本所有固定哈希，复制独立运行时，生成新入口，运行继承与新增回归并构建两个ROS包。
实际源文件只能通过apply_patch修改；脚本仅生成独立构建输出，不修改父版本。
确认通过后仅将现有eventio入口指向该输出，`finalize.py --output <同一目录>`严格校验此次获授权的单一路径迁移。
原入口的完整字节备份在输出的`previous_eventio_launcher.sh`；父运行时、父清单以及长按/旧单击/矩形入口均保留。
父清单仍记录迁移前入口哈希，恢复备份入口可恢复父清单核验；不得删除校验项或忽略其他漂移。
`--check`只核对文件、既有刷写读回记录和配置；不代表此刻重新读回板上固件，也不初始化ROS或启动车辆。

新流程需要另行实机验收；离线通过不代表已完成新的实机运动测试。
