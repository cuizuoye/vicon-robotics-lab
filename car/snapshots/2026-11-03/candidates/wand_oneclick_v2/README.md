这不是Vicon刚体模板/标记点匹配的根治；准备检查通过也不保证运动中
永不翻转。再次翻转仍必须停车。需要先在Vicon端消除car01的姿态翻转，
再安排新的人工确认实测。本轮不启动小车，不刷写，不修改ESP32、网络、
固件、已验收3×3m基线及原矩形程序。
