# 4WSC 档0落地初验（独立入口）

此入口用于取得新固件的第一批真实动作与停车观察数据，不是“已通过停车、电流和温升审核”的长时演示。是否完成离线交付以 `LATEST_PREPARED.json`、对应 `HOST_MANIFEST.json` 及其证据为准。不会把未知测量填成已通过，也不更改原600秒演示的准入规则。

## 固定参数

- 仅档0：平移≤0.20m/s、加速度≤0.08m/s²；旋转≤0.20rad/s（约11.5°/s）、角加速度≤0.80rad/s²；PWM≤35%、轮目标≤100RPM。
- 1:1原始Sign水平位移＋相对旋转，Z不作运动指令；无绿色中间参考点、无固定电子围栏。第一次只在车旁小范围移动，不是要求走遍采集区。
- 一次启动最多60秒：监督器、末级门与操作台均有限时；不支持升档、600秒、自动续跑或原地重复准备。
- 浏览器主线程证明100ms、命令100ms、定位200ms、MCU反馈300ms、操作租约150ms；底层600ms链路看门狗及原堵转、过零/换向、姿态/抬起、来源/签名保护均保留。
- 仍是固定限值下的连续跟随，不是误差自适应加速度算法。低档速度慢，不能用这一轮判断最高档同步性。

## 启动命令

仅在小车已经落地上电、接线固定、Sign与car01实时可见、动作范围空旷且有人能立即断电时，执行：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_4wsc_ground_test.sh --launch --site-ready
```

`--site-ready` 是执行者对**当前现场条件**的声明，同时确认这是尚未物理合格的受控初验，不代表已测过停车距离或温升；不需要在窗口再点三个勾选框。程序自动完成：

1. 文件、真实刷写读回记录、独立初验参数准入检查。
2. 8秒HELLO＋失能零速握手；不清故障、不使能。Tenda须已连接，不修改Wi-Fi或默认联网路由。
3. 复用唯一且来源/坐标参数正确的只读Vicon接收器；没有时自动启动已核验接收器。本入口退出时只关闭自己启动的接收器，外部进程不动。
4. 实际ROS监督器、末级门与独占传输完成失能建基准；Sign/car01无新帧、时钟或故障检查不通过，就不会开放操作台。
5. 浏览器自动准备，直到显示READY。**打开、准备不会自动运动；需要操作者按一次并松开空格。**

若浏览器没有自动打开，用终端本轮打印的完整地址打开；不要沿用旧地址、旧操作台或旧实机启动命令。

## 这一轮怎么做

1. 先把Sign拿到舒适高度、五点无遮挡并拿稳，等READY。
2. 按一次并松开空格。先沿车头方向平缓移动杆约20cm、停住等车追上，再收回；方向不符立即Esc，不重复试。
3. 正常后再向左小幅移动并收回，可补小角度旋转后转回。不要快速大幅甩杆，也不要靠近人员、障碍物或跟踪边界。
4. 最后在车仍跟随时按Esc，观察是否停稳；或者等待最多60秒自动结束。松开空格不会停车，再次空格/Esc/停止按钮才停止。
5. 若反馈、定位、方向、声音或接线异常，立即Esc，必要时断电；保留页面提示与日志，不在旧窗口反复准备。没有可信反馈时只能报告“停车未确认”，不能凭界面认为物理已经停稳。

本轮不要求悬空，不重新刷固件。完成后需要操作者说明方向、返回、旋转、Esc停车及有无异常；日志会自动保存在Linux端。

## 记录与仍待完成的测量

每轮记录原始配对反馈、故障、原始时间戳、Sign目标、car01位置、轮RPM/目标/占空比，以及停止前后的Vicon位置。`MEASUREMENTS.json`给出50ms窗口的速度观察、停止请求后的轨迹长度和数据连续性。

这些是**正常停止观察**，不是“已验证600ms失联回退的完整停车包络”。缺帧、未确认停车或尚未运行都会如实保留未知/未通过。只进入ACTIVE不等于车轮真的起转，须结合原始RPM、Vicon轨迹和现场观察判断。

没有电流或温度传感器，普通万用表也不能自动提供温升数据；电池电流、驱动板/电机温度继续为未知，不把软件测试、手感或旧固件记录伪装成本版测量。当前实验配置不能直接作为原600秒或高档的合格凭据。

## 安全的文件检查与纯软件排练

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_4wsc_ground_test.sh --check
```

只核对文件，不打开硬件或初始化ROS。纯软件排练使用 `--rehearsal`，只连接专用127.0.0.1端口、合成Sign和原版native C软件代理，不能连接真实ESP32。独立真实ROS域126、软件域193；原入口的域/文件不变，实际UDP端口另有全局独占锁，禁止多个控制器同时运行。
