# 独立单击空格模式（离线候选）

`小车单击 --check`只核对文件及既有Flash读回记录；`--preview`只打开离线启动页。
普通启动也不使能：先确认现场、准备、等READY，然后轻按并松开空格一次。
第一次完整单击在释放沿提出启动请求；再次空格在按下沿立即撤能，Esc或停止按钮也可结束。
松开空格不再停车，单独拔下键盘也不能当作可靠的停车动作；须有人随时能断电。

没有模拟长按。物理key_down与逻辑session_requested分开；旧Lease.held布尔位
仅为兼容既有协议承载逻辑请求，并通过新的模式标识、审批种类和签名scope隔离。
长按自动重复不切换；失去KeyRelease时轮询只取消启动，不会合成启动；启动点击
有效期1秒，UI调度间断仍按原100ms保护撤能；启动确认超过1秒也撤销请求。

计时从后端第一次健康ACTIVE捕获原点开始，最多120秒，不从打开/准备开始。
一轮一次；第二次空格、Esc、失焦、关闭、异常或到时结束后不能自动恢复，
也不能在同窗口再按空格重启。遮挡/翻转/围栏/来源/通信保护保持，底层150秒不改。
继续1:1、0.70m/s与0.80m/s²、前[-1.5,.5]/左[-.4,.5]m及四边50cm缓冲。

原`小车`、`小车120`、矩形程序、固件、网络和已验收记录均不改。
新模式有独立启动页单实例标识；仍共用原始UDP独占锁/端口与唯一来源门，
不会抢占旧程序、杀进程或允许两个控制器同时驱动。
此轮不启动ROS/Vicon/实车，不刷写；单击实车行为、电流、温升、停车距离未验收。
