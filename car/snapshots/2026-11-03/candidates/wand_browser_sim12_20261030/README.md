# 真实Sign → 浏览器SIM12（独立软件候选）

## 一条命令

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_browser_local.sh
```

等价专用命令为`bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_sign_browser_sim_1p2.sh`。启动前保持实车断电/未连接，Tracker实时采集，Sign五点可见。入口先校验源码、真实Sign完整新帧和原几何定义，再在失能零速下完成DDS冷启动及连续0.75秒稳定基准，之后才打印地址并请求默认浏览器打开。

网页显示READY后，轻按并松开空格开始；再次空格、Esc或停止按钮结束。松键不停。结束、失焦、隐藏、断连或故障后不自动恢复，也不在旧页面中复用运动权限；要重新运行命令建立新会话。`--check`只核对文件和证据，不初始化ROS；`--no-open`只打印地址。原只读显示试验保留为`bash .../start_car_browser_local.sh --readonly`。

## 保留与替换

- 复用未修改的SIM12速度/加速度/几何定义、源身份绑定、监督器、独立末级门、专用签名及数学执行器；私有DDS191、随机命名空间。
- 直行≤1.20m/s；共享轮速预算下45°斜向合速度≤0.849m/s；平移加速度≤4.00m/s²；转速≤2rad/s、角加速度≤12rad/s²。平移与旋转叠加共享轮速余量，不保证同时各自满速。1:1 XY和相对yaw，Z不映射，无固定电子围栏，最长600秒。
- 仅将Tk窗口、应用内同步X11键盘查询替换为浏览器本地Canvas与前台主线程挑战回应。源码可能复用纯控制节点所在模块的导入，但不会构造Tk窗口或X11键盘对象。
- 使用既有独立控制/画面通道和有界最新画面槽；保持100ms原始挑战/浏览器主线程保护、150ms操作员租约、200ms定位保护和300ms模拟执行器反馈保护。持有租约必须使用原挑战的单调时间，后台不能重标时间续命，画面ACK不能产生运动权限。
- 不接受鼠标/网页虚拟位置指令，仅真实Sign（或自动回归专用的显式合成数据），car01只读记录，不用于软件车反馈。
- 原Tk演示、原矩形程序、密封4WSB以及旧浏览器候选均未修改。无电机桥、ESP32/Tenda配置写入或固件刷写。

## 证据边界

`test_protocol.cjs`是非浏览器协议测试客户端，显式合成手势，通过真实ROS监督器/安全门验证大范围平移＋旋转、无启动键不使能、挑战超时、双通道断连、第二次空格、重放/虚拟位置拒绝及定位遮挡停车；它不能代替真实浏览器前台调度或真人Sign验收。

故障后不自动恢复的核心证据也复用SIM12既有遮挡恢复测试；当前遮挡协议测试在停车后关闭软件进程，不冒充同会话遮挡重新出现的完整人工验收。原桌面卡死根因尚未确定，浏览器短测通过不等于GPU/桌面问题已修复。默认浏览器自动打开请求须在实际主机验证，工具预览使用本机内置浏览器。

数学执行器为未辨识的一阶模型，时间常数0.12秒，无实际电流、热、摩擦/饱和动力学。测试通过不是硬件可达1.20m/s、4.00m/s²或实车停车时间的证明。
