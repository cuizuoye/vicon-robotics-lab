# Sign旋转方向只读预览（第一步）

此入口与现有标定杆平移、矩形和固件独立，只订阅域0的Sign、五个命名点以及car01，不创建速度/使能发布器，不连接ESP32/STM32，不占用小车UDP端口。
仅复用已经运行、来源校验通过的Vicon接收器；不修改或重启它，不改变Tenda或电脑网络。

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_sign_rotation_preview.sh
```

实车保持断电。窗口默认1280×720，最长10分钟只读观察；不是120秒实车演示入口。

1. 拿稳Sign，全部五点可见。程序将同一源时间戳的刚体位姿与五点组成一帧，转换到Sign局部坐标后拟合T形。所有候选均显示，不在多解时自行选定。
2. 核对蓝色三点是短横杆，绿色/黄色箭头确实朝横杆外侧、背离长柄，勾选确认后点“确认这组三点”。真实点号由读数识别，不预设Sign1、2、3为横杆。
3. 杆拿稳，点“记录零角（只读）”。这只记录Sign与car01的初始航向，不使能小车。初始两者不必绝对同向。
4. 将杆绕竖直方向左转约30°、停住、转回，再右转约30°并转回；应显示同号、同幅相对转角，目标车头示意也转相同角度。
5. 遮挡、输入过期、来源冲突、点位/刚体姿态不一致、角度跳变或参考方向接近竖直时零角失效。露出不会自动续算，须再次手动记录零角。抬杆不作为平移/旋转指令；本入口根本没有平移输出。

三个共线点只确定横杆轴线。使用其余长柄点消除正反歧义，并把前方向量固定在Sign局部坐标；运行时通过完整四元数旋转该向量，再投影到水平面。不会因四元数q/-q等价或±180°表示换边而反向。
本步保守要求五点同帧用于定义和核对，不宣称已支持部分遮挡跟踪。将来实机控制仍需独立监督器、旋转参数与固件分档验收。

`--check`只做文件核对，不初始化ROS；`--headless --seconds 6`是有限时订阅读取，不自动确认横杆或记录零角。
结果写入独立`docs/wand_rotation_preview_2026-10-26/readonly_*`，含来源记录、原始输入、相对角度与人工确认事件。
初始实测快照来自用户确认断电后的被动订阅，不能替代后续真实转杆方向验收。
