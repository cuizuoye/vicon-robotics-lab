# 标定杆指挥小车：离线映射与仿真验收

日期：2026-10-22。此阶段仅验证软件映射与仿真，不连接或启动实车。

## 已实现的操作约定

- 启用时同步记录杆与车的当前位置，小车启动朝向作为固定前/左参考。
- 水平位移比例2：杆前进0.5m，小车目标前进1m；杆收回时目标回到小车起点。
- 杆的高度、朝向不映射成小车运动；车头保持启动朝向。
- 暂停后可将杆收回舒服位置，再次启用时两侧重新对齐，不追赶旧目标。
- 启用期间车被推偏，位置闭环回到当前杆指令的目标；不依赖矩形路径。
- T形五点作为一个刚体输入。本轮只使用模拟刚体位姿，未测量实物杆尺寸或创建真实Vicon对象。

代码以独立ROS包 src/mecanum_wand_control 交付。已有控制包72个文件的SHA256前后一致，矩形程序与固件未修改。仿真仅使用 /wand_sim 下的话题、隔离ROS域97/98/99和本机发现，不加载硬件桥。

## 验收证据

新包47项测试与现有包275项测试通过，独立ROS包构建通过。

| 虚拟时间场景 | 起步朝向 | 最大到位误差 | 结果 |
| --- | --- | --- | --- |
| 前进1m再返回 | 0度 | 13.24mm | 通过 |
| 左移0.5m再返回 | 90度 | 13.66mm | 通过 |
| 斜移(0.8m,0.6m)再返回 | 60度 | 11.46mm | 通过 |
| 注入约0.32m位移和0.30rad转角扰动，再回位与返回 | -40度 | 11.89mm | 通过 |

四组场景均满足合速度不超过0.15m/s、合加速度不超过0.30m/s²、到位误差不超过25mm的验收条件。目标映射的比例本身精确为2，实际仿真车保留15mm到位容差，因此不会刻意追求零误差。

实际ROS节点之间的验证在隔离域98运行：仿真小车100Hz反馈、杆50Hz输入、控制器50Hz输出。初始车头90度，杆前移0.5m后车约到0.99m；返回误差约12mm；暂停再对齐没有明显跳变；杆输入中断约0.22s后输出锁存为零。冻结时间戳、非法四元数也会停止，恢复数据后不自动启动。结束状态STANDBY，节点正常退出。

域97完整96秒演示也已通过：起步车头60度，依次前进返回、左移返回、斜移返回；观察9698条小车反馈，状态仅STANDBY→ACTIVE→PAUSED，最终返回误差11.29mm。RViz成功加载仿真配置及OpenGL环境。

长演示初次运行曾因输入时间戳有效性检查触发停车，未算通过。最终版把可视化从50Hz控制回调分离为10Hz、无订阅者不构造绘图数组，并允许5ms以内的小幅源时钟偏差（钳制到接收时刻，不能把未来时间用于续期）；0.20s输入超时保持不变。随后短程ROS验收和96秒长演示均重跑通过。

## 复现与观看

    cd /home/PRIMARY_USER/vicon_mecanum_ws
    source /opt/ros/jazzy/setup.bash
    source install/setup.bash
    ros2 launch mecanum_wand_control wand_sim.launch.py

默认弹出RViz，运行96秒自动演示后暂停。绿色T形点是模拟杆、橙色球是目标、蓝色小车和曲线是仿真响应。取消GUI可追加 start_rviz:=false。

重复自动验收：

    ros2 run mecanum_wand_control wand_offline_suite --output /tmp/wand-results
    ros2 run mecanum_wand_control wand_ros_smoke --output /tmp/wand-ros-results

完整操作与服务说明见 src/mecanum_wand_control/README.md。

## 未覆盖的真实因素

模型复用原有二维惯性/轴向增益仿真，没有模拟轮地摩擦、车重、打滑、无线链路和真实遮挡重建。实物T形杆的刚体识别稳定性、参考点原点和握持偏移仍未验收。不能把本报告的毫米级仿真误差当作实车定位或行驶精度。

下一阶段先把真实杆位姿只读接入目标预览，观察静止噪声、遮挡和重新出现；之后再迁移到实车。
