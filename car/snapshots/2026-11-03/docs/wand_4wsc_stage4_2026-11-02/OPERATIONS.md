# 4WSC 档4受控落地测试

本入口复用已验收的1:1直接平移＋相对旋转控制器、原版4WSC固件和ROS末级输出，不是新无级调速算法。仅允许明确授权的**档4、最多60秒**实验，不构成高档或600秒物理合格证明。

## 参数与前置事实

- 平移速度上限0.70m/s，加速度上限0.80m/s²。
- 旋转速度上限1.50rad/s（约85.9°/s），角加速度上限6.00rad/s²；本轮先小幅缓慢转杆，不追求旋转极限。
- PWM上限80%，每轮目标不超过400RPM；平移与旋转同时输入仍服从共同轮速约束。这是允许上限，不是持续按上限运动。
- 1:1原始Sign水平位置＋相对角度，Z不映射；无绿色中间参考点、无固定围栏。定位覆盖不代表避障。
- 本版4WSC档0已真实动作并人工停止，原始结果和用户正常反馈作为哈希固定的前置观察。该观察不是档4停车、电流和温升数据。
- 当前现场须保持：小车落地上电、朝向正确，Sign/car01实时可见，接线固定，运动和停车区域空旷，有人能立即断开电池，旧控制器已退出。

## 一条启动命令

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_4wsc_stage4_test.sh --launch --site-ready
```

只有独立快照离线验收、固件读回记录、上述档0原始证据、当前声明及失能握手检查通过后才开放浏览器。首次连接自动准备，READY仍不运动；要单击并松开空格才开始。首次打开时确认页面显示档4、0.70/0.80和60秒，不能沿用旧标签页或旧地址。

1. Sign拿到舒适高度、拿稳，等READY。
2. 单击空格开始。先向前平缓移动约20厘米、停住、收回，再向左小幅移动并返回，确认方向正确。
3. 正常后可在已确认空旷区域内逐渐加大到约0.6～1米往返，观察平移、换向、返回；可补约20°～30°的平缓转动并转回。不要甩杆、大角度快速转动或突然把目标移到远处。
4. 再次空格、Esc或停止按钮结束；**松开空格不会停车**。最多60秒自动撤权，不自动升档、不续跑、不自动恢复。
5. 异常立即停止，必要时断电。保留页面与提示，不在同一窗口反复准备。等待STOPPED_CONFIRMED、现场确认车停稳后再切出页面回复。

浏览器失焦/隐藏/画面断连、100ms控制或页面证明中断、200ms定位超时、300ms MCU反馈超时、150ms租约超时、底层600ms链路看门狗以及原有姿态、堵转、反向/换向、签名和来源校验均保留。没有新鲜可信反馈时只报告停车未确认，不能凭界面当成物理停稳。

## 数据与权限边界

日志保留Sign目标、car01轨迹、原始轮RPM/占空比、状态和源时间戳；退出后生成正常停止观察。操作者需反馈方向、同步性、换向/返回、停止和有无异响。提前人工停止不是故障，也不表示已跑满60秒。

本轮不刷写、不改ESP32/Tenda/默认网络路由、不覆盖档0/原矩形/原演示。停车包络、电流、驱动板/电机温度没有测到的仍为未知，绝不把档0或软件代理的数值当作档4物理数据。正式600秒、高加速度和更高档的准入不随本轮自动放开。

真实ROS域127、软件测试域194；与档0、正式600秒入口分别隔离。物理UDP46001保留全局独占锁，发现其他控制器占用时失败，不停止外部进程。只读Vicon接收器只复用经核验的唯一进程，退出时只关闭本入口创建的进程。
