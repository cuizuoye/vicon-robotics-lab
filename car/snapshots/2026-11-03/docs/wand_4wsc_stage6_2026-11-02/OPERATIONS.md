# 4WSC 档6受控落地短验

目的：在档4已完成60秒实车运行、正常停止且操作员反馈通过之后，保持0.70m/s速度上限，提高平移加速度至2.00m/s²，检查同步性、换向/返回和运动中的正常停止。这里仍是固定限值下的连续跟随，不是独立无级调速实验算法。

## 本轮固定合同

- 仅档6：平移0.70m/s、2.00m/s²，旋转2.00rad/s、12.00rad/s²；这些都是允许上限，不强求手持动作触及极限。
- 每轮目标≤400RPM、PWM≤80%，底层PWM变化率与共享轮速约束按原版档6合同执行。平移与旋转叠加时不能同时无条件达到所有单项上限。
- 1:1原始Sign水平位置与相对角度，Z不映射，无绿色中间目标，无固定围栏。Vicon不是避障系统。
- 单次最多60秒，不能自动升档、延长600秒、自动恢复或重复使能。
- 浏览器/控制证明100ms、命令100ms、定位200ms、MCU反馈300ms、租约150ms、底层600ms链路看门狗，以及姿态、堵转、反向/换向、来源、签名与停稳保护原样保留。

## 前置与启动

本版4WSC档4的原始运行结果、正常停止观察、合同及操作员“高速档演示通过，操作正常”的反馈均绑定哈希，作为允许短时下一档实验的依据；它们不构成档6停车包络、电气/温升或600秒合格证明。未测项目仍未知。

只有当前小车落地上电、朝向正确、Sign/car01实时可见、接线固定，运动及停车区域空旷且有人能立即断开电池、旧控制器退出时执行：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_4wsc_stage6_test.sh --launch --site-ready
```

程序核对文件、固件读回记录和前置观察，再做8秒失能零速握手与真实ROS/Vicon建基准。自检失败不开放网页，不清故障、不改网络。自动准备不运动；READY后需操作者新的单击空格才开始，工具不发送开始动作。

## 本轮动作

1. Sign先拿稳，页面保持前台；确认显示档6、0.70m/s、2.00m/s²及最多60秒。
2. 单击空格开始。先做约20～30cm的小幅前后、左右往返，确认方向、返回和换向无异常。
3. 正常后在已确认空旷区域内逐渐增加至约0.6～1m的平缓往返；可补小幅转动并转回，不甩杆、不追求旋转极限，不贴近障碍物或跟踪边界。
4. 本轮请尽可能在车仍有明显平移、前方空旷时按Esc结束，观察正常停车；不必等满60秒。这会提供比“计时结束时已静止”更有用的正常停止记录，但不是600ms失联急停测试。
5. 再次空格/停止按钮也可停车；**松键不停**。异常立即停止，必要时断电。停止后不在旧窗口反复重试，保留提示和日志；现场确认停稳、页面显示STOPPED_CONFIRMED后再回聊天反馈。

满60秒自动停止或主动正常停止都可作为本次观察；主动停止的原始 `completed:false` 不应修改成跑满计时。反馈缺失时保留STOP_UNCONFIRMED，不能凭网页认为物理已停。

## 数据与边界

记录Sign目标、car01源时间戳与姿态、原始轮RPM/目标/占空比、门控和停止过程。正常停止后的Vicon轨迹不是包含600ms失联回退及车体外廓的高速停车包络；未实际达到的峰值与加速度不能当作已测试。电流、驱动板/电机温度没有传感器的保持未知。

本轮不刷写STM32，不改ESP32/Tenda/默认网络路由，不覆盖档4、档0、原矩形或原演示。正式600秒/更高档的准入不变。真实ROS域128、回环测试域195，签名范围独立；实际硬件端口保留全局独占锁，发现外部控制器时拒绝而不停止它。只读接收器只关闭本入口自建的进程。
