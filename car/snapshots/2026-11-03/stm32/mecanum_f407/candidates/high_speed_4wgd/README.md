# 4WGD 独立高速候选：先0.20m/s，轮速目标最终封顶400RPM

状态：**离线源码、静态/单元检查、STM32镜像和独立ROS软件包构建完成；没有刷写、没有运行ROS节点、没有发送实车指令。** 原4WGC和现有0.05m/s操作台保持不变。用户仅反馈现有低速全向跟随基本正常，不将该反馈写成高速动作验收。

## 参数与含义

- 依据操作员确认的MG310：减速比20:1、7～13V、输出轴空载500RPM。80%目标为400RPM，不重复乘除减速比。
- 标称轮径60mm、既有各轮CPR `[3179/3,1049,3167/3,1061]` 和方向符号`[+1,-1,+1,-1]`全部复用；未重新测量或伪造高速标定。
- 400RPM对应理想直行轮缘速度1.2566m/s；纯对角平移的理想合速度上限0.8886m/s。它们不是1.4kg实车加载后的保证速度，也不是可以在现有2×2m区内达到并安全停下的承诺。
- 用户接受首档0.20m/s，再逐步提高。独立实机入口现在只支持0.20m/s、0.08m/s²合加速度、0.10rad/s偏航；2倍相对XY映射、忽略杆Z/姿态、目标引导及边界限幅不变。0.30/0.50/0.75/1.0/1.20只列为离线规划档，不在真实入口中自动开放。
- 400RPM是每个电机的请求目标上限；独立原始反馈故障阈值440RPM用于量化/过渡余量，原10000cps异常保护仍保留。瞬时实际转速不可能由目标限值绝对保证。
- PWM独立保守封顶80%，起动补偿仍≤30%/500ms；**80%占空比不等于80%转速**。此电源上限不构成电机电流或温升合格证据，更不保证负载下可到400RPM。
- PI、前馈、800cps/s目标斜坡、换向过零和实测中立等待复用现有算法。没有重新辨识高速PI/前馈。以最大CPR估算，0→400RPM的目标斜坡约8.84s；在短工作区内通常到不了该最高档，不为追求数字擅自加大加速度。

## 保留的保护

600ms底层断令、150s固件绝对额度、120s电脑端会话、200ms位姿/反馈新鲜度、100ms指令期限、150ms操作员租约、10ms采样/30ms最大间隔、堵转、持续反向证据、实际PWM/CCR/已授予方向检查、全车故障停机、失能及急停都保留。正常零目标/停机立即清驱动，换向不能延长绝对预算；真实硬故障不能用健康计时重置来清除。

`Src/four_wheel_speed.c`仅包装接受的4WGC算法，为每轮增加RPM目标/反馈检查。`Src/mecanum_drive_plan.c`通过线性齐次缩放复用原规划器，不独立截断各轮。编译时核对原4WGC十个文件及其原基线哈希；漂移时拒绝构建。4WGD诊断身份`0x44475734`、156字节/v1，绝不伪装4WGC；旧入口拒绝D。

## 停机不是刹停：未完成的现场项目

本地WHEELTEC手册第10页表3-1-2明确：IN1=IN2=0是高阻滑行，IN1=IN2=1才是短接刹车。现有固件停机两路LOW继续保留；没有擅自增加反向制动或短路制动。

因此首档实机也不能直接照搬0.20m旧余量。独立审核要求：

1. 以0.20m/s测得的滑行距离、固定场地与Vicon覆盖余量；保守余量至少为`0.20m基础余量 + 0.20m/s×0.60s底层兜底期限 + 实测滑行距离`。此式不是物理最坏情况认证。
2. 电机持续/峰值电流、3S母线压降、驱动及电机温升和供电/线束可靠性。额定≤0.5A不等于堵转电流，也没有装上电流传感器的假设。
3. 独立刷写前现场断电确认、完整Flash备份、候选授权与独立读回一致、真实失能准入，之后才进行分级动作验收。

当前所有高速专用现场确认均为false，滑行距离为null，硬件入口在构造Node/socket前拒绝。不能为启动而手工填true或随意填测量数字。固定车体名义活动区仍沿用原起点前2m/左2m的设计；若停车余量增加，应重新审核外围固定围栏，不能悄悄缩小/平移用户要求的活动区或宣称Vicon覆盖已验证。

规划函数示例：若**仅假设**减速度0.20m/s²，首档总停车预留约0.42m；400RPM轮缘速度时约4.9m。减速度尚未实测，这些数字只是说明不能沿用低速边距，并非现场安全结论。
