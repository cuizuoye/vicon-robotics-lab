```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_browser_local.sh --readonly
```

统一命令目前默认已升级到真实Sign→SIM12浏览器仿真；显式加`--readonly`才能复现本文件的旧显示试验，Python launch.py自身行为未变。

只读分支请求系统默认浏览器打开本机随机端口的网页，显示120秒软件动画。终端保持打开；网页需保持前台并点击一次获取焦点。可先用`--readonly --seconds 60`，`--readonly --no-open`只启动只读服务并打印完整地址，`--readonly --check`只核对旧显示试验、不启动服务。

本入口复用已密封的`wand_browser_fast_2026-10-28/prepared`及其校验，不修改旧浏览器候选、原本机演示、SIM12或矩形程序。保留Host/Origin/随机令牌校验、单所有者、100ms前台主线程证据、控制/画面分流及有界最新画面队列。网页后台化、失焦、断连、卡顿或Esc都会结束该轮，不自动恢复；需重新运行命令获得新地址。

当前是显示层验证，不是跟随控制：动画不是实时Sign输入，空格不会使能任何车。没有初始化ROS、打开Vicon接收器、连接ESP32/Tenda、小车运动或固件写入。现有真实跟随参数和安全保护未改。真实Sign→浏览器仿真及实车网页迁移仍需单独实现验收，不能用只读动画代替。

使用浏览器可绕开旧Tk Canvas和应用内同步X11键盘查询，但浏览器仍依赖桌面/显卡，因此本轮无卡死不等于原系统根因已消除。首次只按有限时长验证，不自动触发最大化/全屏压力复现。
