# 清晰大字版操作台（仅显示层）

字体由14--16物理像素改为正文22px、日志/辅助20px、关键提示及停止按钮24px、标题30px。
以用户对Codex字体的可读性感受为参考，不读取或更改Codex/桌面DPI及系统字体设置。
维持1280x720、原三个现场确认、自动检查与准备、单击空格启停/Esc停车。

只添加显示层mixin；所有原ManualApp和Console方法保持原样。正常停止/急停的回调、
键盘bindtags、原点捕获、120秒、安全门、200ms反馈保护、网络和固件不修改。
实车页隐藏重复的只读小圆盘及其禁用鼠标按钮，保留大字Sign数值、主地图和所有安全状态。
启动页确认文案压缩，含义和实际勾选变量/回调不变。旧版备份及快捷命令迁移均有哈希记录。

发布后仍使用一条命令 `小车演示`，关闭旧窗口后重新打开生效。不自动打开实车会话。
