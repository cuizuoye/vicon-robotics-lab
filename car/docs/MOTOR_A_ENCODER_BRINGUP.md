不强行退针。优先请原电机商家提供配套件，并标注每路功能。

- 需要插头能够直接插到该 MG310 电机接口，另一端六路分别可接触、可留空，

- 必须确认 `VCC、GND、A、B、M+、M-` 的对应关系；不能直接套用厂家资料中

### 选定的隔离接法

第一阶段不用 D157B 给编码器供电，改用现有 DCP3512 的 **5V 输出**，
且在连接编码器前重新测量该输出。之前的 4.92 V 是 D157B 的测量结果，
不能当成此次 DCP3512 输出的确认值。

```text
电池 -> DCP3512 -> 已测量的 5V/GND -> 分线件 -> 编码器 VCC/GND
                                        A/B -> 先只供万用表测量
                                        M+/M- -> 分别悬空并绝缘

两块 D157B：不接电池，全部 Motor_A/Motor_B 口保持空置
STM32：第一阶段不接编码器 A/B，不接电机驱动输入
```

| 电机端功能 | 分线件上的处理 |
|---|---|
| VCC | 线序确认后接已测量的 DCP3512 5V |
| GND | 接 DCP3512 GND |
| A | 留作电平测量，暂不接 PB4/PB5 |
| B | 留作电平测量，暂不接 PB4/PB5 |
| M+ | 不接任何电源或驱动输出，单独绝缘 |
| M- | 不接任何电源或驱动输出，单独绝缘；不是编码器 GND |

当前先等待配套分线件；未确认转接线序前，不执行此图的上电步骤。
后续先空载测量电源，再断电接编码器、复核供电极性和动力线悬空，最后才上电
测 A/B 电平。物理隔离不依赖驱动板开关、软件停机或 AIN 接地状态。

## 第 3 步：手动旋转，实测输出轴每圈计数

仅在接线、电平、安全供电均确认后执行；保持电机绕组断开。
先验证轻转时 `enc` 改变、反向时计数方向相反，再开始标定。

1. 在输出轴或轮毂上做对齐标记，记录静止时的累计计数 C0。
2. 同方向手动旋转输出轴 N 个完整圈，回到对齐位置，停止后记录 C1。
3. 计算 `每圈计数 = abs(C1 - C0) / N`，建议 N=10，并重复两次及反向一次。
4. 保存原始 C0/C1、圈数、方向和重复结果。用本工程的实际累计计数计算，
   不再额外乘 4 或减速比；多圈平均可能不是整数，不盲目取整。

不自动写入标定值，也不发 `hb`、`arm`、`duty`、`speed`、`brake` 或清故障命令。
先确认测量一致性，后续再决定标定值及轮速换算。
