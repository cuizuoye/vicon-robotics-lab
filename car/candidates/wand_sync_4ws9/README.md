# 4WS9 v5：平移＋旋转同步跟随独立离线候选

不是自主导航：沿用 Sign 交点位置＋水平角度遥操作，持续由控制器自主闭环跟随。
位移和角度均1:1，Sign1—Sign5—Sign2为横杆，车头背离Sign3/4长柄。
Sign5为平移参考；启动中性帧同时记录车/杆位置与角度。Z不映射，竖直航向退化停车。

档6是已有人体验较好反馈的A2软件参数，不是首次实机档位。每轮目标RPM依档
100/180/250/400封顶；反馈上限120/210/280/440。正常命令按统一比例缩放，
保留合速度/合加速度，不逐轮裁剪。禁止运行中换档和自动升档。

原0.10rad/s纯旋转最大约82cps，低于现有100cps起动门槛，可能只有跟随目标而
不转轮。新首档0.20rad/s约164cps；保留原起动门槛、30%起动助推和限时保护，
不靠降低门槛掩盖问题。是否能带载起转仍需悬空及落地验证。
极慢微转和最终几度内的起停仍可能受原有死区及实际起动力矩影响，离线模型
不能承诺消除；不在缺少实测时提高最小PWM或降低堵转/中性保护。

## 改动与保留

- 新固件身份4WS9、v5、200字节诊断、0x7900/0x7980选档；旧4WS8命令不能选档。
  新诊断携带本档角速度、角加速度、轮速上限和耦合斜坡版本，主机独立校验。
- MCU 100Hz只做一个正常SI矢量斜坡；平移＋旋转共享插值系数，轮速公共缩放。
  配套主机50Hz沿用无位置低通、40ms源时间速度估计、速度前馈＋位置纠偏。
  不取消MCU防御性速度/加速度限制，不宣称传感器曝光到轮子的硬实时保证。
- 重入轮速斜坡按本档平移/旋转加速度推导；每轮反转仍需实测中性30ms，
  750ms换向截止不能由抖动刷新。堵转、反馈反向、零目标轮撤能和急停仍保留。
- 末级门绑定同一原始Sign+五点帧digest和car时间戳；缺帧按序有界等待，坏帧
  不被新帧覆盖。错源、翻转、混帧、重放、过期不能续命；停车帧不等待来源。
- 新ROS包 `mecanum_wand_4ws9_*`，硬件域121，固定命名空间 `/wand_4ws9_sync`。
  独立HMAC v5逐档域。原平移、低速旋转、A2仿真、矩形、ESP32和Tenda均不改。
  这是文件/入口保留，不是刷入新镜像后同时兼容旧实机入口；旧4WS8入口会因
  身份不符拒绝4WS9。需要回原实车演示时，应按完整备份回滚，不能伪装旧身份。
- 最新已确认区域是前[-1.5,.5]、左[-.4,.5]米，不是历史3×3或整个Vicon覆盖。
  190×210mm旋转车体、四边50cm缓冲及20cm硬停余量不变。
- 保留120秒、一次使能；单击空格启动，再次空格/Esc、失焦、遮挡停车；松键
  不停车，不自动恢复。定位/反馈200ms、主机命令100ms、操作租约150ms、
  底层后备600ms和总150秒预算不放宽。大字1280×720保留。

## 离线入口与硬件边界

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_sync_4ws9.sh --check --stage 0
```

默认只验文件，不启动ROS、不连接设备。新固件必须获得单独刷写授权，电池断开、
ST-Link连接后完整备份1MiB、写入并独立完整读回核对。没有新镜像记录，
`--launch`在打开设备前拒绝。旧4WS8记录、仿真结果和旧场地确认不能代替。

悬空入口已有左旋/右旋，单次最长5秒；需要新镜像刷后记录＋当次现场确认。
从档0先方向/停止，再逐档；绝不从档6开始。真实Sign遮挡/停止/人工重开
和旋转负载验收仍单列，离线通过不记作实车通过。

## 停车、电气及温升验证预案

1. 新镜像失能握手：核对4WS9/v5/200字节、档0、故障零、时钟合格，四轮零输出。
2. 固定悬空，人在断电处；档0先前进、再左右小角速度，各独立最多5秒。
   记录四轮目标/实际轮速、PWM饱和、反转中性和结束停稳。普通万用表只在VIN
   做直流压降初筛，电流档绝不可并接电池；无需重复以前不便观察的无效测量。
3. 小范围落地另行授权，分别量平移及旋转的松键逻辑停止（本模式第二次空格/Esc）、
   失焦和遮挡停车包络。失联后备600ms：0.70m/s仅延时已走0.42m，2rad/s
   已转1.20rad，尚未含实际滑行。软件加速度不是实测制动减速度。
4. 使用190×210mm完整旋转轮廓评估角落扫掠；在实际地面、1.4kg/左后电池布局
   下复核，不能用固定朝向小矩形或悬空平顺代替。包络不适合当前缓冲则不升档。
5. 普通万用表不能证明瞬态电流、再生尖峰和温升；驱动板默认每路1.32A、
   标称4A/峰6A以及电池110C标签不构成实际带载资格。未知BMS额定值不补写通过。
   无测温工具时温升仍为未量化，不以手摸或“没异响”认证高档连续运行。

本轮全部硬件资格保持未通过，所有配置是NOT_APPROVED；准备好后再通知接硬件。
