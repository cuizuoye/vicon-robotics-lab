# 平移＋旋转：现有4WS8硬件兼容的独立迁移候选

保留 `小车演示` 和矩形程序；不改固件、ESP32、网络或原文件。本轮只生成私有
ROS包、操作台及回归证据，不连接实车。原启动门控修复、大字体1280×720及单击
空格启停继续沿用；自动准备不等于自动使能。一轮120秒、一次使能，无自动恢复。

- Sign1—Sign5—Sign2为横杆，Sign3/4为柄，车头朝横杆外侧、背离柄。
- Sign5交点作为平移参考；启动时同时记录车/杆的位置和角度。准备后拿起或调整杆
  不消耗位移/角度，首次中性ACTIVE帧才建原点。平移方向仍固定于启动小车坐标。
- XY与相对水平角均1:1，可叠加；Z不映射。抬腕/竖直导致水平航向退化则停车。
- **沿用实机档4：XY .70m/s、.80m/s²；yaw .10rad/s、.40rad/s²。** MCU源码
  硬上限也是 .10rad/s、.40rad/s²，不是仿真A2的2rad/s、12rad/s²。旋转90度仅
  匀速理论时间就需15.7秒。本候选用于打通功能，不承诺A2同步性或带载转动成功。
- 最新已确认区域为前[-1.5,.5]、左[-.4,.5]米；四边50cm缓冲和20cm裕量保留。
  不是历史3×3米，也不推断整个Vicon覆盖。按实际旋转的190×210mm车体检查围栏。
- 原平移入口的启动朝向偏差0.20rad保护由新入口专用角参考连续性、角度跳变、
  .65rad跟踪误差、.50rad角参考领先和3秒旋转无进展保护替代；不是裸删除保护。
- XY/yaw统一缩放守住400RPM，每个方向的过零/堵转/反馈反向保护仍由原MCU处理。
- 监督器与末级门分别接收原始Sign+五点同帧包。每个候选绑定原包digest+stamp及
  原始car时间戳，独立几何核对、缓存选帧和航向重建。错源/混帧/重放/过期不续命。
  这是本机ROS源身份/一致性检查，不宣称DDS加密认证。
- 保留200ms定位/反馈、150ms使能租约、100ms主机命令、600ms底层后备撤能、
  时钟/姿态/急停/故障保护。松键不停车，再次空格、Esc、失焦、遮挡等停车。

只核对文件（默认行为）：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_xy_yaw_demo.sh --check
```

后续经现场确认才可用 `--launch` 打开未使能候选窗口；本轮不执行此命令。
历史平移悬空/落地成绩不能写成新旋转实机验收。旋转须先安排小角度、停车与方向
首验，再叠加平移；提速需另行准备有新身份/分档、停车包络的固件，不能只改参数。
