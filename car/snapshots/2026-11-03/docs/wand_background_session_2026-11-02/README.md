# 后台独立演示模式 V1（内核说明）

正式入口已更新为 [后台独立演示入口](../wand_background_session_display_2026-11-02/README.md)。下面的启动/停车命令也指向已修正停车显示的入口。

## 启动与停车

现场条件确认后，在本机终端运行：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_standalone.sh --launch --site-ready --operator-trial --seconds 600
```

先显示启动检查页。自检通过后自动进入跟随界面；真正READY后，轻按并松开空格启动。本模式**切换应用、切换标签页、最小化或暂停绘图均不撤销已启动会话**。

网页回到前台后，再次空格、Esc、停止按钮结束本轮；软件急停按钮仍请求锁存急停。网页不在前台时，Esc不是全局停车键。可以在另一个本机终端输入：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_standalone.sh --stop
```

终端停车命令只发STOP，不启动、不恢复、不清故障；必须收到本轮停车和零输出确认才报告成功。若失败或未确认，立即检查实车，必要时手动断电。

关闭演示标签页、刷新/导航离开演示页、关闭浏览器或浏览器连接断开仍会停车。启动器终端需保持运行，Ctrl+C结束也会请求停车。这不是无人值守模式，仍须有人监护并能立即断开电池。

无参数或 `--check` 仅校验本地文件；不会连接或启动实车。旧版 `start_car_tracker_fixed.sh` 和原矩形程序完整保留，不会自动切换到新模式。

## 权限与安全架构

```text
网页：显示 + 明确的START/STOP意图
                  │ 单次新鲜START口令（1秒有效、消费后失效）
                  ▼
后台会话主循环（100ms期限、单次会话、最多600秒）
                  │ 每轮检查，不依赖网页刷新或焦点
                  ▼
原ROS监督器 → 原末级门 → 原验签桥 → 原ESP32/STM32
      ▲              ▲
 Sign/car01新鲜定位   机器人通信与故障反馈
```

- 不再用浏览器的100ms主线程回应、窗口焦点或画面ACK作为持续运动授权。没有后台线程伪造浏览器焦点、按键或心跳；新模型的`focused`一直为False，单独使用`backend_available`。
- START需操作者在前台完成一次可信点击。失焦只取消尚未完成的点击；不会在返回时补启动。服务端验证启动口令、序号、当前READY条件，拒绝迟到或重放的START。每会话最多一次授权，停车后不自动恢复。
- 运动授权由明确的后台限时会话产生。后台主循环100ms停顿、Node到控制器指令通道100ms中断仍会撤权。Node健康监测有原始单调时钟，迟到的积压消息不能刷新授权。
- 保留控制命令100ms、定位200ms、机器人反馈300ms、STM32链路600ms、硬件故障、唯一控制源、验签和停车确认；不自动清故障。
- 急停仍锁存。如果急停后正常反馈链路不再给出停车确认，界面和启动器仍显示“未确认”并阻止重启；不会仅凭门控零输出伪称实车已停稳。软件回归另外检查原生C模型确已撤销驱动且PWM/目标轮速为零。
- 后台HTTP/控制通道与浏览器绘图分离。画面只有一个在途帧和一个最新待发帧，暂停绘图不会堆积历史轨迹，恢复后显示最新状态。
- 运动参数不变：1:1平移和相对旋转；0.70m/s、2.00m/s²、2.00rad/s、12.00rad/s²；600秒。无新增中间参考点或固定围栏。
- 不刷固件，不改变Tenda设置，不修改电机控制或原矩形程序。

## 验证边界

新模式以 `prepared_v1/QUALIFICATION.json` 的实际结果为准。回归使用专用随机回环端口、ROS域196、合成Sign和真实原生C固件模型，**不是实车运动验证**。没有打开机器人UDP46001，也没有改动实体固件或网络设置。

浏览器初始准备使用受控的前台测试环境；背景观测前关闭Playwright焦点模拟，读取真实`document.hasFocus()`与浏览器窗口最小化状态，并冻结真实渲染线程。这台X11环境在窗口最小化后仍报告`document.hidden=false`，报告如实保留，没有伪造该值；隐藏事件处理由客户端单元测试覆盖。

600秒上限已保留。此版本没有宣称完成新的完整600秒后台耐久或实车验收；需后续现场监护复验。
