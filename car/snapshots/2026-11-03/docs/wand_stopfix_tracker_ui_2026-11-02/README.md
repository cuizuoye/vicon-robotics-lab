# Vicon Tracker 风格世界坐标视图

独立展示版本 `TRACKER_WORLD_UI_V1`，基于精简界面 `DEMO_UI_V1`。仅修改画布渲染、图例与画布样式；旧入口和原矩形演示保留。

## 坐标与显示语义

- 使用现有 ROS `map` 中的米制 X/Y；接收器强制校验 `map_xyz=[0,0,0]`、`map_rpy=[0,0,0]`，所以沿用当前 Vicon 世界原点，不把车辆起点当作世界原点。
- 深色二维俯视网格、原点十字、红色 X 轴、绿色 Y 轴，正 X 向右、正 Y 向上。两轴比例一致。
- 正常视距下主格 1 米、细格 0.2 米。大位移时只扩大视图，并相应更新刻度，原点不平移、不旋转，也不会因返回自动缩放而抖动。
- 蓝色 `car01` 是实测小车位置及现有标定车头方向；橙色 `Sign目标` 是原有 1:1 平移与相对旋转映射生成的目标，不是手中 Sign 的绝对位置。没有增加中间参考点。
- 物体图标保留最小可见尺寸，中心位置按真实坐标绘制；图标边框不是安全足迹或停车距离证明。
- 未提供相机外参，因此不根据照片猜测相机位置，也不绘制虚构的相机、检测边界或障碍边界。网格不影响运动许可。

## 保持不变

控制发布、ROS 监督器、末级门、验签、传输、自动准备、空格/Esc 操作、速度/加速度、600 秒时限、定位与通信时效、失焦/遮挡/断连停车保护均不变。保留上一版精简展示，不重新加入已删除的日常说明；故障原因和停止/急停按钮保留。

本轮仅离线测试，不启动实车，不刷固件、不改网络。回环 ROS/C 固件测试不是实车运行证明。浏览器预览使用没有真实网络或电机连接的显示夹具。

## 启动

结束旧会话、关闭旧网页，确认现场条件后：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_tracker.sh --launch --site-ready --operator-trial --seconds 600
```

自检通过后自动打开，READY 后单击并松开空格开始，再次空格或 Esc 停止，松键本身不停。不要运动中刷新页面。

文件检查不访问硬件：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_tracker.sh --check
```

原精简入口 `/home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_demo.sh` 完整保留作回退。

报告、坐标投影检查和 1280×720 / 1920×1080 预览见 `prepared_v1/QUALIFICATION.json` 引用文件。
