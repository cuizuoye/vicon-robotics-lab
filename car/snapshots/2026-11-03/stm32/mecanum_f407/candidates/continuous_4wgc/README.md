## 控制变化

四轮目标仍由同一麦克纳姆运动学方案统一计算、同比例限幅并整体提交；不独立随意改某轮的运动学目标。每轮保存“请求目标”和“当前有效斜坡目标”两个量：

1. 同方向更新按800 count/s²变化；非零目标的正常每10ms变化不超过8 count/s。
2. 该轮收到异号请求时，先以原方向受限减速；积分清零，关闭起动补偿。
3. 有效目标到零后，该轮PWM保持零。真实原始测速绝对值≤100 count/s、滤波测速绝对值≤60 count/s，且此前输出为零，持续至少30ms后，才授予新方向。
4. 新方向从零斜坡加速。其他轮继续自己的控制，不再仅因单轮正常换向而让整车等待500ms。全部轮都需要同时换向时仍可能有必要的共同零输出阶段；不承诺物理上毫无减速。
5. 单轮换向总期限为`ceil(进入换向时有效目标绝对值/800×1000) + 750ms`。后续相同异号目标不刷新期限，迟迟不能测得低速会保护停车。750ms是减速后的额外等待预算，不是任何速度下的总换向时间。
6. 明确的零目标、失能和急停仍可立即清PWM、积分与有效目标；不让平滑斜坡延迟安全断能。

所有非零驱动输出均限制变化率；量化后的10ms样本在本轮测试中最大变化10permille。输出符号必须与当前有效斜坡及已授予方向一致，而非强制与尚在减速中的未来请求符号一致。执行器比较寄存器仍整体校验，失配不允许部分下发。

## 反馈保护：不是全面忽略反向

- 超过原10000 count/s反馈上限，任何阶段（含零目标、换向）均立即故障，不设过渡豁免。
- 低速抵消轮可能被车体被动带动。当有效需求不足100 count/s，或前一拍实际PWM不足静摩擦前馈80permille时，不把单个方向不同的计数当作电机反接。它也不能充当有效的起动/防堵转正向进展。
- 有明确驱动能力时记录反向净证据。正确方向计数可抵扣证据；普通目标更新不清空证据或重新开始计时。
- 反向累计达到12 count立即停车；较小反向证据达到3 count并持续60ms停车；若再次出现反向计数且距首证据达100ms也停车。因此允许少量短暂拾载/量化过渡，但持续反向不是无限豁免。这里的时间窗口只有在仍出现反向证据时才触发，不因一次孤立噪声后静止而自动报方向错。
- 起动500ms无正确进展、已有进展后的原堵转门限、600ms断令租约、30ms最大采样间隔、绝对150s底层运动预算、速度/PWM限幅、重放/外来会话/CRC校验、失能、ESTOP均保留。换向、零目标和新速度包不能延长绝对额度。
- 真正故障仍整车停车并锁存，健康预算重置不清除真实故障。
