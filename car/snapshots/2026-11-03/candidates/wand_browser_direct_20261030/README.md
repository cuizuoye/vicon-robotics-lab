# 浏览器 · Sign 1:1直接跟随（独立软件候选）

本轮只改软件仿真；不刷固件、不构造硬件通信桥、不启动实车。旧矩形、Tk和已封存SIM12入口保持不变。

启动：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_sign_browser_direct.sh
```

保持实车断电/未连接，Tracker输出Sign新帧。自检后自动打开本机浏览器，READY后单击空格开始；再次空格、Esc或停止按钮结束。松键不停车；失焦、遮挡、通信过期仍会停车，不自动恢复。每个窗口一轮，最长600秒。

## 本轮控制差异

- 蓝色仅为软件车；橙色仅为Sign的1:1位置和相对水平角度，Z不映射。
- 删除绿色中间目标及其位置限速、20cm超前冻结、0.50rad角度超前冻结；不是只改颜色或隐藏图形。
- 删除以该中间点为前提的0.65m/0.65rad追踪误差锁止；大而有效的手势是需求，不等于定位故障。
- 控制直接使用真实Sign目标，40ms因果速度估计前馈＋位置误差反馈，保留一次最终耦合轮速/加速度整形。
- 独立末级门从相同原始Sign五点报文、摘要及小车时间戳重新计算1:1目标；伪造目标、换源、重放、不合法起始帧不能通过。
- 初次有效零速ACTIVE时捕获原点；准备之后拿起/调整杆不会引起跳动。停机不复用原会话。

## 不变的边界

纯平移合速度≤1.20m/s，轮缘共享预算导致45°斜向≤0.849m/s；叠加旋转时共同缩放，故并非无限速1:1。
平移加速度≤4m/s²，角速度≤2rad/s，角加速度≤12rad/s²；均为软件实验参数，不代表现有硬件已支持。
浏览器证据100ms、控制报文100ms、操作者租约150ms、定位200ms、数学反馈300ms、独立调度100ms保护保留。
原始位姿跳变、刚体几何、抬起/倾斜、无运动进展、签名、防重放、停车确认继续有效。
无电子围栏不等于避障。

`compare.py`为相同目标输入的离线数学模型对照，`test_direct.py`为改变路径的注入时钟回归；真实ROS协议故障注入与实际浏览器验收单独记录。植物模型τ=0.12s未经实际电机辨识，不能将这里的跟踪误差当作真车延迟。
