实车保持断电。Vicon/Sign就绪后自动检查和准备，READY后单击空格开始，再次空格或Esc停止；松键不停车，失焦、遮挡、故障仍撤权。最长600秒，结束后此窗口不再启动，须关闭并重新打开。

- 1:1 XY与相对旋转，Z不驱动，无固定电子围栏。
- 直行1.20m/s，45度斜向合成约0.849m/s；正常轮速预算约382RPM，假设驱动绝对上限420RPM，旋转共享预算并等比例缩放。
- 控制加速度4.00m/s²，角速度2.00rad/s，角加速度12.00rad/s²。这些是软件设定，不是物理性能保证。
- 200ms定位、100ms指令/验签/界面、150ms操作员租约、300ms反馈保护不变，禁止自动恢复。
- 新Sign仍是原物理T形，Tracker重建后编号改变。本实验独立定义横杆Sign1—Sign4—Sign3、中心Sign4、长柄Sign2/Sign5，朝横杆外侧为正方向。原演示定义未改。
- 复用既有4WSB主机监督器、末级门、同源验证及操作台；全新SIM签名域拒绝实车输出。执行器是tau=0.12s名义数学模型，没有运行STM32 C固件，没有电流、温升、摩擦和真实机械辨识。
- 本轮不修改原演示、矩形、4WSB候选、已放弃的1.40m/s草稿、Tenda或接收器二进制，不刷固件、不启动实车。
