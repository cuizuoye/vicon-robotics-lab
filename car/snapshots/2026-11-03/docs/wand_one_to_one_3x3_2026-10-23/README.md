## 区域和50厘米的定义

采用原矩形起点`(0.6437034797013303,-1.0528685411524479)`米及原车头朝向
`1.526260405304856`弧度为固定世界参考，不随每次准备、恢复或杆重新取原点移动。

- **绿色目标区**：车中心向前0～3米、向左0～3米。Sign XY为1:1；最终目标在此限幅。
- **红色物理缓冲外框**：在3×3米车中心轨迹的参考车体外缘外，再各留0.50米。
  车长190mm、宽210mm，因此对应空旷范围约4.19×4.21米；考虑任意转向时按约4.30×4.30米规划。
- **橙色虚线硬停中心边界**：在红框内检查实际旋转车体，并保留原0.20米额外余量。
  原朝向时车中心允许范围为前/左各`[-0.30,3.30]`米；不是可以把目标放到这里。
  保留20厘米意味着保护在物理缓冲外缘之前触发；实际转向时边界按车体投影收缩。
- **紫色杆参考区**：目标区每侧额外0.50米，仅是输入参考，不代表自动验证过该区域的Vicon覆盖。

50厘米是空间缓冲，不是实测停车距离，也不批准0.50m/s或400RPM运动。
本版仍只允许0.20m/s合速度、0.08m/s²电脑命令加速度、0.10rad/s偏航、35% PWM。
车体脚印、20厘米额外余量、抬车/倾斜、定位/反馈/操作员/指令时限、MCU600ms断令、
120秒电脑会话、150秒MCU额度、来源签名、实际方向/CCR及故障停车仍保留。

目标半径改为4.75米，保证3×3远角（约4.243米）及允许的起点偏差可达；
这不扩大目标方框，因为最终目标独立限于0～3米。
最终目标与即时参考使用不同的投影边界，起点放在名义区外几厘米时参考从实测位置平滑进入，
不会为贴回目标区边缘而瞬间跳变。围栏始终固定，不把越界伪装成重新定位。

## 启动入口

仅检查数据、不启动任何ROS节点或硬件：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_wand_1to1_3x3.sh --check
```

需要人工确认后打开真实操作台（本轮未执行）：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_wand_1to1_3x3.sh --launch
```

先停止并关闭旧控制入口。脚本在人工终端要求确认扩展区/缓冲空旷、Vicon覆盖、原参考及立即断电条件。
确认时只更新当前现场布尔声明，不改几何/速度，不把停车、电流、温升填写为通过。
模板漂移、已有运动桥或非人工终端会拒绝；每次新建独立现场profile和日志目录。
启动后仍需轻按松开空格解锁、准备、就绪后持续按住空格；松键/停止/退出仍停车，不自动恢复。
