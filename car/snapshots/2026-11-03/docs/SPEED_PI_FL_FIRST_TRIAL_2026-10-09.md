# 左前轮首次悬空速度PI试验

日期：2026-10-09。当前板内speed_pi_v2，USART2 115200文本；本次只执行一次FL正向动作，未改接线、热点、代理或虚拟网卡。现场已确认停轮并断动力，最终检查通过。

## 本次结果

目标300计数/秒；由PI调整PWM，不是固定占空比演示。按FL近似CPR1059.67，目标约16.99RPM。主机约4.7秒主动stop，固件独立5秒上限保留。

- 47个运行遥测样本，首末MCU时标108790/113390ms，相隔4600ms；采样/测速更新均100.00Hz，周期最小/最大10/10ms，中断耗时记录最大65us。
- 最后一帧运行状态：目标300cps，原始300cps，滤波308cps，PWM5%，实际CCR100/95；FL累计+1073，其它三轮计数保持0、控制目标/输出均0。
- 后段17帧（相对首运行帧3000至4600ms）滤波平均307.94cps、相对目标平均偏差+2.65%、平均绝对误差10.41cps（约3.47%）；按近似CPR换算约17.44RPM。它们只是此短时悬空窗口统计，不是编码器精度、长期控制精度或负载性能认证。
- 全程遥测最大PWM7%，后段最大6%，低于10%限幅；最大滤波速度326cps。没有在线增加增益、修改限幅或自动重试。
- 停机末帧ms114040：FL=1096，其余轮0；四路速度/目标/输出和8个实际CCR归零，fault=0、wdg_reset=0、used=1。运行末帧之后多23计数属于停止后观测到的增量，stop是高阻滑行，不声称立即机械停轮。
- 操作者确认“仅左前轮朝前转动并自行停止，其余静止，已断动力”；共同车头参考下，左前顶部轮面朝车头。
- 断动力后另做5秒只读检查通过，ms311950至317640：计数稳定FL1098/FR3/RL3/RR3，四路速度及8个CCR为0、无故障、used=1。与上次末帧之间没有连续观测，少量计数差不当作本次受控运动或硬件异常证据。

结论：左前轮首次受限悬空PI试验的协议、隔离、方向、观测速度及现场停轮检查通过；开始具备实机单轮轮速闭环证据。不代表PI已充分整定或全车已能落地/Vicon轨迹跟踪。

## 固件及主机保护

- 独立speed_pi_v2精确协议；旧arm/duty、speed_pi_v1及921600二进制MC-Link均不可用于当前板内程序。
- 初次运行前必须连续零输出/无计数变化500ms，最后采样不超过30ms；stop也重置静止观察。
- 每次复位仅允许一次run；开始尝试即消耗额度，stop不恢复，故障不自动清除。再次试验必须先断动力再复位、无动力检查和新的上电确认，不能在上电状态随意复位。
- 固件只允许一个选中轮，100/200/300cps及相应负值白名单；本次主机运动入口更严格，只允许唯一run FL 300 S5。
- 最大输出10%、目标斜坡200cps/s、滤波50ms；起始Kp=0.1千分比/cps、Ki=0.5千分比/计数，未在线整定。CPR为用户采用的台架近似值，轮径为标称60mm。
- 心跳/目标150ms超时、最多5秒、采样间隔超过30ms、起动800ms无计数/运行后500ms无进展、选中轮反馈反向或非选轮计数变化均停机锁存。
- UART有界队列与非阻塞发送；异常锁存停机。IWDG名义约500ms，可运行版不冻结调试看门狗。本轮尚未用实机故障注入检验超时、急停、调试停核或看门狗期限。
- 主机每约50ms发心跳；调度迟到、遥测断流、固件拒绝/故障、隔离或方向异常即退出并发stop。4.7秒先stop；固件独立5秒兜底。所有软件退出、CCR记录都不能替代现场观察与断动力。
- ro=0、gpio_low=0是可运行版PWM复用模式，不是引脚电压读数；末帧实际CCR为0不能替代示波器波形验收。本轮没有声称做过波形实测。

## 使用入口

工作目录stm32/mecanum_f407。动力已拔掉、未用额度的启动检查：

```bash
python3 -B tools/speed_pi_probe.py /dev/serial/by-id/usb-1a86_USB_Serial-if00-port0 --mode no-power --confirm-battery-disconnected
```

当前额度已用尽，断动力后只能用post-run模式（只stop/status，无心跳和run）：

```bash
python3 -B tools/speed_pi_probe.py /dev/serial/by-id/usb-1a86_USB_Serial-if00-port0 --mode post-run --confirm-battery-disconnected
```

fl300模式具备运动能力，只有在现场重新完成断动力复位/检查及悬空上电确认后才可使用；不要把上面已断动力确认参数与已上电状态混用。
