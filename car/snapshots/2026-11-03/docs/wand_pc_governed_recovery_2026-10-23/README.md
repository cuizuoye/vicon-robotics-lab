# Sign电脑端目标引导和恢复修复

范围：只修改专用Sign电脑端及其测试/配置。未刷写任何芯片；ESP32、Tenda网络设置、STM32候选源/镜像和原矩形控制文件不改。无动态车模或真实ROS故障注入，本轮使用纯函数/状态机单元、静态合同检查、原记录回放及实际失能准入。

## 行为

最终目标仍为启动时捕获的车原点加Sign的2倍水平位移，忽略杆Z/姿态，并按原固定围栏和3m会话半径限幅。新增显式governed策略，默认direct不变：最终目标与即时参考点分离，参考点按0.05m/s和0.04m/s²规划，以20cm正常超前上限等待车跟上，不把参考点拉回被外力挪动的车。最终速度合成仍≤0.05m/s，合加速度≤0.08m/s²，偏航原限值不变。

保留65cm异常偏差保护；末级门独立重复偏差检查和参考步长/速度检查。持续有平移输出但3秒内未取得至少1cm实测位置变化则CAR_PROGRESS_TIMEOUT；更新杆目标不会直接重启该计时。此保护不是碰撞/人员检测，也不替代固件堵转或物理断电。

反馈超过200ms仍立刻撤销旧会话，失能停车；返回的新数据不能复活原epoch。普通disable保留原时间戳真实诊断，不伪造失能/零输出、不续期旧包、不跨MC-Link session转移缓存。

新增recover服务及“确认并重新准备（不运动）”按钮。只接受故障已消除、松键、实测停稳的PAUSED/非硬FAULT；明确请求后重新累计0.6s稳定窗口，只到ARMED/新epoch，仍须新按住空格才ACTIVE。重新握手和健康预算重置仍先完成失能基线检查。等待中再次故障、提前按键或5s超时会取消。硬故障/执行器故障不允许用此入口解除。新engage重新捕获原点，旧未完成目标不续跑。
