# 精简演示界面 DEMO_UI_V1

基于已通过失能零速检查的 STOPFIX 反馈修复版，独立保存展示层修改；不替换原入口，不更新正在运行的页面。

## 本次界面调整

- 去掉标题与参数行中的试运行、未量化说明及重复档位。
- 去掉图例括号内说明和画布左上角的围栏/障碍说明。
- 去掉右侧正常状态下的连接、安全状态标题及通信调度指标。
- 去掉底部红框内的松键、失焦、遮挡和断连说明。
- 保留实际参数、蓝色小车及橙色目标、位姿、倒计时、运行状态、停止和急停按钮。
- 发生故障或停车时仍显示原因；删除展示文案不删除对应保护。

## 保持不变

1:1 平移与相对旋转、0.70 m/s、2.00 m/s²、2.00 rad/s、12.00 rad/s²、最长 600 秒及无固定电子围栏均不变。

100 ms 浏览器输入/画面保护、200 ms 定位时效、300 ms 小车反馈时效、600 ms 底层看门狗、失焦/遮挡/断连停车、故障不自动恢复均保留。启动前的时钟、故障位与失能零速自检也保留。停车距离、电流与温升未量化的事实仍记录在原档案和运行配置中，不能因界面简化而视作已验收。

本次没有刷固件、更改网络设置、访问电机端口或启动实车。仿真测试仅使用隔离域 196 和独立回环端口；浏览器截图来自无真实网络连接的显示夹具，不是实车运行证据。

## 启动新版

先结束旧会话并关闭旧网页，确认场地与现场断电条件后执行：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_demo.sh --launch --site-ready --operator-trial --seconds 600
```

自检通过后打开浏览器，READY 后单击空格开始，再次空格或 Esc 停止。松键本身不会停车。不要在运动中刷新或切换页面。

不访问硬件的文件完整性检查：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_demo.sh --check
```

原 `/home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_stopfix_feedback.sh` 完整保留，可用于回退原界面。原矩形演示未改。

验证记录和截图见 `prepared_v1/QUALIFICATION.json` 引用的文件。
