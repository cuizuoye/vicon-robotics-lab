# 后台独立演示入口（正式采用此入口）

本版本继承后台会话内核，并修复过大的诊断结果无法发送到网页、迟到画面覆盖最终停车状态的问题。完整诊断留在Linux端，网页只接收有界的停车结果。原前台保护版及原矩形程序不变。

## 启动

先确认现场仍空旷、接线固定、Sign/car01实时可见，有人能立即断电；旧运动入口已关闭。然后输入：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_standalone.sh --launch --site-ready --operator-trial --seconds 600
```

自检通过自动进入网页，READY后轻按并松开空格启动。**启动后可以切换应用、切换标签页、最小化网页；界面暂停绘图也不会结束后台会话。**

## 停车

回到网页再次空格、Esc或点停止；急停按钮仍锁存。

网页在后台时，Esc不是全局快捷键。可在另一个本机终端执行：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_standalone.sh --stop
```

此命令只发STOP，并等待停车及零输出确认；不启动、不恢复、不清故障。未确认时不能把“请求已接受”当成车已停稳，必要时立即断电。

关闭/刷新演示页、关闭浏览器、连接断开、退出启动器仍会停车。启动器终端需保持运行。没有变成无人值守系统，监护和手动断电能力仍是现场条件。

## 保留项

- 最长600秒；1:1平移及相对旋转，0.70m/s、2.00m/s²、2.00rad/s、12.00rad/s²。
- 无中间参考点或固定电子围栏。Vicon有效不等于场地无障碍。
- 后台主循环100ms、后台指令通道100ms、控制命令100ms、定位200ms、机器人反馈300ms及MCU保护不变。
- 启动是单次显式人工意图，不是持续浏览器心跳；没有伪造焦点或按键。失焦只取消未完成的启动点击。
- 停止、故障或超时后不自动恢复；急停后缺少正常停车确认时仍锁止，不假造确认。
- 窗口恢复只显示最新数据：一个在途帧、一个最新待发帧，不回放积压的历史轨迹。

## 验证状态

回归报告为 `prepared_v1/QUALIFICATION.json`，覆盖真实浏览器窗口切换、最小化、渲染冻结、独立停车、关闭网页、定位遮挡、后台进程卡顿、倒计时和最终停车显示。

这些是专用回环端口、ROS域196和原生C固件模型的离线证据，不是实车运动验收。本轮不刷固件、不改Tenda设置、不启动实车。新的完整600秒后台耐久和实车现场复验仍待完成。

底层架构与完整边界另见 [后台会话说明](../wand_background_session_2026-11-02/README.md)。
