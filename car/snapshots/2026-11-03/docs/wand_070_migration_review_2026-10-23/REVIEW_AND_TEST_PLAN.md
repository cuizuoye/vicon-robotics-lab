# 0.70m/s、2.00m/s²实机迁移审查与验证方案

日期：2026-10-23。**结论：现有4W20不支持直接使用该参数；已有4WGD也不能直接复用来获得仿真同步性。硬件速度有运动学上的可能，但加速度、停车、电流及温升尚不具备实机准入证据。**

本轮只读取程序、历史读回及资料，进行离线计算并制定方案。
没有连接设备读写Flash、没有发送UDP/串口/ROS指令、没有启动实车或修改网络；
没有修改原矩形、4W20、4WGD、旧操作台或已完成的仿真程序。
普通万用表是用户目前唯一确认拥有的测量工具；**当前不能开展完整高速电气/温升验收**。

## 2. 速度够不够：直行、横移和对角不能混为一谈

使用既有60mm轮径与45°麦轮运动学，不再次乘除20:1减速比：

| 0.70m/s车体平移 | 最快轮所需轮缘速度 | 所需输出轴转速 |
| --- | ---: | ---: |
| 直行或纯横移 | 0.700m/s | 222.82RPM |
| 45°对角 | 0.990m/s | 315.11RPM |
| 最不利对角＋0.10rad/s航向修正 | 1.005m/s | 319.76RPM |

航向修正使用**轮心几何**0.061+0.085=0.146m，不把车体外廓半长/半宽误用为运动学尺寸。
400RPM上限在运动学上够用；这不等于1.4kg带载、横移/转弯时电机一定能达到。
500RPM是用户提供的空载值，80%转速与80% PWM并不等价。

2.00m/s²在理想均匀载荷、无摩擦/无转动惯量的估算下：

- 总平移力约2.8N；直行每轮约0.214kgf·cm。
- 对角主要驱动的两轮各约0.303kgf·cm，已经占用户额定0.4kgf·cm约76%。
- 未计麦轮滚子损失、传动损失、轮子/转子转动惯量、左后偏载及航向修正。
  不能由理想估算小于额定扭矩就断言可达到；也不能无电机常数直接反推出精确电流。

## 3. 固件最关键的缺口不是400RPM，而是800cps/s

4W20/4WGD复用的连续轮控及四轮组都将`ramp_cps_per_s`固定校验为800。
默认未标定配置中的200不是实际已采用参数；实际初始化明确写800。

| 项目 | 既有轮速目标斜坡折算 | 0.70/2.00的需求 |
| --- | ---: | ---: |
| 直行车体加速度等效值 | 约0.142m/s² | 2.00m/s² |
| 对角车体加速度等效值 | 约0.1005m/s² | 2.00m/s² |
| 0→0.70m/s目标爬升 | 直行至少4.93s；对角至少6.97s | 理想0.35s |
| 每轮cps斜坡 | 800cps/s | 直行约11258；对角约15921cps/s |
| 对角＋0.40rad/s²航向修正 | 仍为800cps/s | 最不利轮约16249cps/s |

这些是目标序列的运动学等效值，**不是实测加速度上限**；实际电机响应可能更慢，
起动补偿/摩擦也会使真实瞬时加速度不按这个数值走。
若直接刷旧4WGD，即使转速能上去，仍有明显的底层加减速/换向滞后。

另外还有：

1. 50ms编码器滤波、1200permille/s输出变化限制、实测近零等待等阶段未在简化仿真执行器里建模；
   不能把仿真的0.12s一阶执行器当成真实STM32+电机。
2. 旧前馈种子`80+0.15×cps`在0.70m/s直行给出约66～67% PWM，
   对角给出约91～92%，超过4WGD的80%上限。
   这说明前馈外推会饱和，必须辨识；**不能仅凭该种子就断言实物一定达不到该速度**。
3. 正常换向有目标回零、实测近零、30ms中立确认等保护，不能为加速简单删除。
4. 现有控制没有电机电流、绕组温度闭环；堵转/超速检测不能代替电流/温升保护。

## 5. 停机输出是滑行；50cm缓冲没有通过高速审查

WHEELTEC输入真值表和芯片手册一致：00为高阻滑行/休眠，11才为低侧短接刹车。
已核对实际四轮固件链：`four_drive_stop`清零四轮占空比，`four_speed_compare(0)`输出CCR对[0,0]，
`four_link_bench_main`采用高电平PWM1，故该停机行为确实是00滑行。
其他旧单电机文件里存在`brake`函数，不表示此镜像调用了它。

**2.00m/s²是要求的正常运动加速度，不能直接当作故障停机时的减速度。**
软件门控归零、PWM归零和车体真正停稳是三个不同时间。

现有固定几何保持不变：名义车中心目标区[0,3]×[0,3]，四边车体外缘到物理外框50cm；
保留20cm额外足迹余量后，参考朝向的硬停中心界为[-0.30,3.30]×[-0.30,3.30]。
车在名义目标边上还有约50cm；**等实际越过硬停中心界才停车时，只剩约20cm车体净余量**，
旋转后还可能更少，必须按实际旋转足迹核算。

仅作敏感性规划：`预留=.20m+v×.60s+v²/(2×假设减速度)`：

| v=0.70m/s，假设减速度 | 估算所需预留 |
| --- | ---: |
| 2.00m/s² | 0.743m |
| 1.00m/s² | 0.865m |
| 0.50m/s² | 1.110m |
| 0.20m/s² | 1.845m |

全表是**假设，不是实测或认证**。即使把滑行距离假装为0，0.70×0.60+.20=0.62m也已大于50cm。
所以目前不能批准0.70m/s一直跑到3m目标边缘，也不能靠放宽现有硬围栏来掩盖停车不足。

而且600ms只从MCU最近接受的命令起算，并非从人松键/PC停止发包起的全链路保证：
ESP32代码会合并连续速度报文，但已查看的ESP/MCU接收路径仍主要按接收时间续租和序号判断，
没有据`sender_time_ms`直接建立可靠端到端年龄上限。延迟但序号更新的包不等于及时的新意图。
必须检查Wi-Fi/队列突发、PC退出、通信中断、UART中断等情形；本轮不修改Tenda或缩短看门狗。

将来有三种可讨论的措施，未选定/未实施：

1. 保持3m×3m目标区，按**实测停车包络**在靠边前主动降速，保留最外层独立硬停围栏。
2. 经现场重新确认覆盖/空旷后增大物理缓冲；不能自动改用户指定区域。
3. 新候选验证有限主动制动和端到端命令新鲜度。11短刹/反向制动涉及绕组电流、母线瞬态、
   MCU掉电后仍为滑行等问题，不能只改一个输出位就宣称解决；即使增加也不能当作断电后必有的制动。

## 6. 仪器条件：只有普通万用表时能做什么

| 项目 | 普通万用表 | 进入高速验收还缺什么 |
| --- | --- | --- |
| 断电检查/授权后的静态母线与5V/3.3V | 可以，仍需正确接法和量程 | 本轮不要求操作或上电 |
| 电池平均直流电流 | 合适的有保险电流档可能粗看，受量程、插孔和压降影响 | 优先借用可记录的直流电流钳/母线功率记录，不反复拆主电源 |
| 四个电机PWM绕组RMS/峰值、换向瞬态 | 不能作为合格证据 | 带宽/采样率足够的双向电流探头＋示波记录；或经评审的隔离测量方案 |
| 母线、5V/3.3V快速压降/尖峰 | 通常不能可靠捕获 | 示波记录及安全隔离/差分测量 |
| 电机/驱动/电池/接头温升 | 目前无测温工具 | 借用接触式温度计/热电偶记录；合适热像仪可补充热点 |

**母线电流不等于绕组电流**；PWM续流/制动电流可能在桥内循环，电池端读数不代表电机发热。
即使写着True RMS，也必须核对DC+AC能力、波峰因数、测量档位的PWM频率带宽和采样率。
本固件PWM为10kHz，不能把普通1kHz带宽仪表当作可用；建议电流波形带宽至少100kHz、
采样率约1MS/s或更高作首验目标，并按波形确认精度/量程与抗混叠，实际设备性能需核实。
低速INA类母线记录可用于能量和压降趋势，不单独用来验收绕组峰值/RMS。

这些原则由[maxon电机PWM电流测量说明](https://support.maxongroup.com/hc/en-us/articles/360012273994-Motor-current-measurement-in-case-of-a-PWM-power-amplifier)
和[厂家电机技术资料](https://www.maxongroup.com/medias/sys_master/8815460712478.pdf)交叉核对；
只借用通用测量/热原理，不把maxon电机的温度或过载规格移植给MG310。

不要求现在购买；**借用仪器做一次集中测量**是更少插拔的路径。
若暂时借不到，先保留已验收仿真与当前实车限制，不把普通万用表数据写成高速电流/温升通过。
不得用示波器接地夹夹到H桥输出造成短路；电流探头、隔离差分/分流器的接法应由有经验人员评审。
本轮不提供带电改线/并接大电流表的执行配方。

### G2：停车包络

- 在场地中心选择足够的直线走廊，留出从该档**假设最差停车距离之外**的余量；

- 每方向至少5次，覆盖代表性高/较低电量、左右运动、不同起停方向和实际使用地面。

- 事件分开测：正常停杆、人工松键、窗口失焦/软件停止、Sign/车体定位丢失、

- 停车距离记录事件后**最大离开事件点距离和各边法向最大外移**，也记PWM零后的滑行，
  不能只记最终净位移或只用编码器积分。静止判据建议车体速度低于0.02m/s持续0.5秒，
  同时编码器及跟踪有效；视频用于独立复核。失去car01跟踪时不得用补帧宣布已停。
- 使用所有重复中的最大值，加测量不确定度、几何/控制余量，而非平均值或最好值。

### G3：电流与电压

- 同步记录母线电压/电流和四个电机的绕组电流，分清平均、DC+AC RMS和瞬态峰值；
  同时记录每轮目标/有效cps、实际RPM、PWM/CCR、反转状态、故障位和Vicon车体速度。
- 热评估按绕组RMS及时间窗，不用电池平均电流代替。
  在没有厂家短时过载许可前，**0.5A/轮只能作保守持续电流筛查上限，不作为允许任意峰值的依据**。
  峰值大小、持续时间和独立切断能力仍须核定；没有可靠峰值控制前不开放2.00m/s²档。
- 任一轮持续RMS达到/超过该暂定上限，或有明显饱和但速度不足、复位、异常声响/抖动、接线热、
  停车超包络，即停测复审，不靠延长堵转时间或增加PWM硬顶。
- 按电池厂家更严格值监测单节；资料未补齐时，可将负载下单节3.5V（总压10.5V仅作辅助）作为
  本次首验的保守停测线，不把它当作电池绝对最低额定值。不能只看总压掩盖失衡。
- 检查5V/3.3V最低值、掉电/复位、换向/刹停母线尖峰及接头压降。
  具体绝对上/下限应从本车实物器件资料取最严格值；不以AT8236的36V上限覆盖电机7～13V或电容/稳压器限制。
- 保留滑行停机。若拟增加11短刹/反向制动，先另做峰值/续流/母线电压方案，不能直接落地开启。

### G4：温升与持续工况

- 环境温度记录；四电机壳、四驱动芯片/板热点、稳压器、电池表面、主接头/线束分别测量。
  不用手摸判断，也不把壳温等同绕组/结温；IR对裸金属需处理发射率与反射误差。
- 首验可先用这些**工程保守停测线**：电池/主接头45°C或温升15°C，
  电机壳60°C或温升35°C，驱动/稳压器表面65°C或温升40°C，任一先到即停。
  不是厂商额定或安全认证；厂家更低值优先，异常气味/鼓包/变色/功能异常即使温度未到也停止。
- 起动5秒、10秒、30秒筛查后，逐步到60～90秒代表性动作；持续记录并检查停机后延迟升温。
- 保留PC120秒、MCU150秒上限。较长观察由例如“90秒运动＋30秒停止”的5个独立会话构成，
  每次按原规则停稳/手动重新准备，不延长会话预算，也不自动循环开新会话。
- 10分钟观察没有热平衡就只认定该间歇演示工况，不能称连续运行通过；
  需要更长工况时另行安排，并受电池单节电压、温度、当前状态约束，不为凑时长深放电。
