# 一条命令打开新手操作台

终端输入 `小车`。启动页会检查文件/固件读回证据、Tenda、Vicon来源和
Sign/car01定位。只恢复已保存且不接管默认路由的Tenda连接；已有Vicon复用，
缺失时才启动经过原有来源校验的只读接收器。不会杀掉其他控制程序。

不再在终端输入长确认口令。在窗口中确认三项现场条件后，打开跟随窗口；
点“准备”，等准备就绪，再持续按住空格移动Sign。物理键盘已确认空格释放时
可解锁UI，不再要求额外轻按一次；绝不会合成按住使能。松键/失焦照常停车。
正常结束不要点“紧急停止”；急停锁存必须检查，不能通过重开窗口自动清除。

启动修复仅适用于本次进程从未收到准备/运动意图、无故障、原生v4失能零输出
且四轮反馈为零的状态；允许历史USED标记存在时，在旧600ms租约结束后重连。
准备后例外永久禁用。200ms反馈期限、运动中断链锁止、故障锁存、认证和来源
检查不变。通信仍不稳定时不允许准备，而不是放宽超时。旧日志显示遥测有
300ms间隔，因此不能承诺只靠界面修复解决真实链路质量问题。

独立运行包不改已验收基线、矩形程序、ESP32或STM32固件。算法仍1:1、3×3m、
50cm缓冲、0.70m/s与0.80m/s²上限、每进程一次且最多20秒。扩区不在本次范围。

`小车 --check` 只核对文件和既有读回证据，不初始化ROS、不连接设备。
`小车 --preview` 只显示离线启动页，没有实车启动通道。
实际GUI链路仍需后续现场验收；当前硬件若已锁存急停，不会自动清除。
