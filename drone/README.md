# MicoAir无人机：真实硬件与SITL分开

## 不能混淆的两个版本

- 真机：MicoAir743-V2-35A，PX4定制1.14.3，board id1179。
- 仿真：PX4 v1.17系列，Gazebo Harmonic，Micro-XRCE-DDS Agent v2.4.3。
  不要把仿真参数、PX4消息定义或成功起飞结果直接用于1.14.3真机。

## 截至2026-10-15

- TRS已用115200高速模式，曾完成电池独立供电的只读通信检查。
- 用户选择PC自主控制、游戏手柄仅HOME锁定输出，不使用传统摇杆控制。
  HOME路径仍依赖电脑/TRS，之前的一次性监听已退出，不是常驻独立急停。
- 已安装固件修补涉及旧MAVLink Shell生命周期/并发、TIMESYNC目标字段和IMU削顶字段。
  保存了源码差异与基线哈希；没有上传厂商固件二进制。详见 `firmware/micoair-v1.14.3/`。
- `MircoAir`重建过刚体：移动了原上方反光点并改到与其余点同高。
  同名不代表原坐标系仍有效。当前刚体版本为 `MircoAir-rebuilt-20261015-U2klYU`。
- 一次10秒、输出锁定、静止的XYZ/yaw融合验收通过，357个位姿包发送，926项参数清理后一致。
  这不是逐包接收证明，也不是完整外参、动态方向、无线独立融合或起飞验收。
- 总体仍**未放行自动起飞/悬停/降落**。旧物理hold、故障守卫和版本全局发送门仍保留。
  不能因为一次例外通过就将全局 `static_validation_completed` 自动设为true。

## 迁移后默认只能离线开发

`tools/gamepad_rc` 保留策略、解析器、HOME锁存和测试；设备UID已换为全零合成值。
原机器的全参数备份、外参候选、许可及消费记录、运行中HOME锁存不公开分发。
没有这些资料的副本不能用于实机发送；不允许临时删guard或伪造物理确认。

从仓库根目录运行 `bash scripts/test_offline.sh drone`。
`scripts/`内的旧SITL脚本是可选历史工具，不由快速开始入口自动执行。
`gamepad_rc.py`旧完整摇杆控制器仍被事件守卫阻止，不是当前起飞方案。

## 接力的重点

1. 保持输出锁定，先离线审查重连、时钟、消息完整性和手柄失联/休眠策略。
2. 所有实机操作都需要重新识别设备、固件和物理状态；桨按仍安装处理。
3. 单独验收无USB时持续定位融合、正确参考坐标和持续HOME监听。
4. 检查真实飞行适配器和失联策略后，才能申请现场试飞；不从本仓库自动发解锁或起飞指令。

Git回退仅回退源码。已刷入的固件、PX4参数、marker布局和安全锁定不会随分支切换恢复。
