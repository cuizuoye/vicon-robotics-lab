## 隔离测试与证据边界

`test_host.py`是禁止ROS初始化/硬件socket/子进程的文件与策略测试。
`ros_rehearsal.py`在私有域191运行实际节点、签名与实际C软件执行器；
`SourceRelay`使用合成只读输入，不要求Sign或car01实物。
软件测试中的自动点击只能在该私有域和命名空间运行，不安装进生产操作台。

`private_display.py`使用隐藏父窗口内的独立Xephyr显示，比较1280×720和
3072×1728无边框画布；不改变桌面分辨率、不把用户桌面全屏化。
它串行跑完整ROS+C链、真实Console和生产日志观察器，独立记录X11/进程/内存/看门狗。
这不等于原GNOME最大化/全屏路径已通过，不能宣布整机卡死已修复。

`acceptance.py`只生成空白计划/观察表，所有物理资格及人工批准为false。
600ms后备断令的停车包络、实车电流/温升、负载与地面滑移必须后续实测。
普通万用表不能证明瞬态电流与温度安全；禁止电流档并接电池、堵转或手挡车轮。
