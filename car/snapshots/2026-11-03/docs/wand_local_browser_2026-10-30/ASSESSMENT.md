# 本机浏览器操作台显示试验

## 已完成

通过本地网页流程，在本机Codex内置浏览器打开了既有浏览器候选的只读界面，显示蓝色软件小车、橙色目标、轨迹、倒计时和停止按钮；截图为`browser_1280.jpg`。没有创建或发布外部站点。

独立的一条命令入口：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_browser_local.sh
```

用户手动执行时会请求系统默认浏览器打开随机本机端口，默认120秒。`--seconds 60`可指定首轮60秒，`--no-open`只打印地址，`--check`只做文件核对。本轮工具验证使用`--no-open`，再通过受控的内置浏览器打开；尚未实际验证系统默认Chrome/Firefox的自动打开路径。
