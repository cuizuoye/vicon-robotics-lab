## 离线代理修正及保留的失败记录

v1的原生预算测试在HELLO前读快照，属于测试fixture错误；v2的短时窗口断言错误拒绝了正确的600秒提示；v3正常软件链出现一次反馈异常撤权，原始日志保留。

调查发现软件固件代理在补算旧控制时间步时，可能把新到报文应用到早于实际接收的时间步，产生不合理的HELLO时钟基准及瞬时负年龄。v4仅修正这个**离线代理**：包括不足1ms的接收小数部分在内，请求只能在不早于接收时刻的控制步处理。新增可复现测试和整套回归通过；真实固件、实际桥接层及300ms反馈/时钟容差未改。该修正不能用来声称过去真实Tenda/ESP32反馈空窗已经解决。

v1～v3均未发布，不覆盖其证据；唯一软件发布为v4。
