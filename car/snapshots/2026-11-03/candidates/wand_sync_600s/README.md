# 600秒平移旋转同步跟随候选

复用已离线验证但未刷写的4WS9分档旋转实现，不重复开发运动学与耦合斜坡。
当前4WS8实车慢旋转的明确软件约束是主机和MCU均限0.10 rad/s与0.40 rad/s²；
这能解释慢转，但不是对实车电机力矩、负载或其他延迟的完整诊断。

本候选独立身份4WSA、输出权限v6、204字节诊断。诊断额外报告630000ms
独立截止，主机600秒到期停车；持续心跳、零速和换向均不能刷新这项预算。
不是自动每150秒重装填，也不绕过固件故障。现用入口及原矩形保持不变。

档4保持现用平移0.70/0.80，角速度和角加速度上限分别比原低速版提高15倍。
最高档来自A2仿真，不是首轮实车许可。后续从档0悬空左右旋转及停车验收开始，
禁止运行中换档、自动升档和使用旧镜像实测记录授权新镜像。

保持1:1 XY与相对角度，横杆Sign1—Sign5—Sign2、车头背离长柄，Z不驱动。
保持现用无固定围栏语义，不把历史范围重新施加为围栏；这不是覆盖测绘或避障。
定位200ms、主机指令100ms、操作租约150ms、反馈300ms、底层断令600ms
不放宽。轮速/PWM分档上限、换向实测中性30ms、750ms换向截止及真实故障
停车保留。长会话600秒不代表峰值动作可持续600秒或电流温升已合格。

默认且唯一开放入口是文件核验，`--launch`在ROS/socket构造前拒绝。
本次仅交付离线固件、主机策略与验证工件，实机启动器接入和刷后准入另行安排。
所有profile均NOT_APPROVED，硬件、电气、温升、停车包络和600秒实车资格均未通过。
