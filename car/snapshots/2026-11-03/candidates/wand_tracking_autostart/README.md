# 无固定围栏版：免勾选自动启动

用户明确要求车放稳、场地空旷、可立即断电三个条件采用默认前提，不再每次勾选。本入口把它们记录为`USER_STANDING_SITE_PRECONDITIONS_V1`，并明确标记`machine_verified=false`和`fresh_human_confirmation_recorded=false`。它们没有变成传感器检测结果，也不伪造每轮人工确认。

启动流程：运行命令 → 自动核对文件/原Tenda独立链路/Vicon → 自动打开操作台和准备 → MCU时钟、零输出和连续停稳等实际安全门通过后显示READY → 必须新的空格轻按/松开才运动。启动器不会发出运动使能或合成空格。失败不跳过、不后台反复重试；运动结束后不自行续跑。

使用前提仍为：车已放稳、活动路径与停车余量空旷、有人能立即断电。软件没有障碍检测，不能检测“人是否能断电”。实际停稳、抬起/倾斜、定位和通信状态仍由原安全链路独立检查。

短命令：

```bash
小车全场演示
```

完整路径：

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_tracking_auto.sh --launch
```

只核对文件、不连接设备：

```bash
小车全场演示 --check
```

SSH/MobaXterm模式原样保留`DISPLAY`和已设置的`XAUTHORITY`；后者未设置时交由Xlib使用当前用户默认授权，不覆盖成Linux桌面的GDM授权。SSH缺少DISPLAY时不误开本机桌面。没有改SSH/X服务器配置或使用xhost放开授权。

默认免勾选仅存在于新入口。原带三勾选的`start_car_tracking_workspace.sh`及其封存文件、原矩形/平移/旋转入口不改。若原窗口仍在运行，新版会要求先正常关闭，不会误显示旧窗口、抢占端口或杀掉其他控制器。

新入口仍是4WS8 v4：位移/转角1:1、平移0.70m/s与0.80m/s²、原角速0.10rad/s与0.40rad/s²、无固定电子围栏、单次120秒。READY后单击空格开始，再次空格/Esc/停止结束；松键不停车，失焦/定位丢失/通信和执行器故障等仍停车，恢复数据不会自动续跑。所有控制器、末级安全门、传输桥和运动操作台源文件与封存父版字节相同；只修改启动器及默认前提的授权表达。本次不刷固件、不启动实车、不改网络设置。
