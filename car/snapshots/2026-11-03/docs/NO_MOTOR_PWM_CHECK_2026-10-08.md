## 固定测试工具

工具：`stm32/mecanum_f407/tools/motor_a_no_motor_pwm_probe.py`。
仅适用于当前115200文本固件，不适用于921600的二进制MC-Link固件。

- 每轮只允许stop、status、hb、arm A5和所选方向的一条duty命令。
  默认`--direction forward`允许`duty 100`，`--direction reverse`允许`duty -100`；
  100是千分比，即10%，同一轮不能切换方向或增大幅度。
- 先同步接收行、确认禁用状态、取得stop ACK和禁用STATUS，再尝试使能。
- 使能必须收到ACK及空载零输出状态，之后只请求一次所选方向10%输出。
- 从请求输出之前按主机单调时钟计时，目标10秒；不是收到ACK后再额外计时。
- 约100ms发送一次心跳，命令之间至少间隔30ms。
- 遥测中断、错误状态、复位、主机调度长停顿、Ctrl-C或SIGTERM时停止心跳，
  尝试stop并查询禁用状态；不自动清故障，不自动重新使能。
- stop无法确认时报告STOP_UNCONFIRMED，要求人工关闭驱动板并拔电池。
- 源码中的500ms固件心跳超时是额外的软件边界，尚不等于真实硬件停机验证。
  Linux调度、USB断连和强制结束进程可能影响主机停机时刻，必须保持电机物理拔下。
- CLI必须显式使用`--confirm-no-motor`。这个选项不能自动检测实际插头状态。

初始正向版本16项离线测试通过。增加固定方向选择后，38项离线测试全部通过；
使用标准库unittest、串口与时钟替身，不打开真实串口：

```bash
cd /home/PRIMARY_USER/vicon_mecanum_ws/stm32/mecanum_f407
python3 -B -m unittest discover -s tools -p test_motor_a_no_motor_pwm_probe.py -v
```

两个方向均覆盖正常限时、命令白名单、缺少确认时不打开端口、分片接收、使能拒绝、
故障、复位、遥测丢失、串口异常、调度停顿、Ctrl-C及停机无法确认。
新增方向不匹配的ACK/遥测检查，以及非法方向在打开串口前被拒绝的测试。
