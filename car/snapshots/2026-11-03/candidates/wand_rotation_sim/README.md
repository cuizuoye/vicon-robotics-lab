# 独立旋转＋平移离线仿真（第二步）

本目录不含ROS初始化、实时Sign订阅、ESP32/STM32接口、UDP或刷写入口。
复用已保存4WS8主机基线的纯XY连续伺服、监督器、末级安全门及虚拟滞后模型，通过独立子类增加相对旋转；不编辑、猴子补丁或放宽原类与实机配置。

已通过第一步的人机方向约定：横杆Sign1—Sign5—Sign2，交点Sign5，长柄Sign3/Sign4；朝外、背离长柄为前方。
新候选的杆端控制点固定为Sign5，完整四元数用于校正刚体原点到Sign5的偏置。原平移入口和固件仍原样保留。
纯旋转测试应保持Sign5不动；若绕手腕旋转而让Sign5实际画弧，这属于真实平移输入，不能假称软件能自动分辨意图。

旋转1:1，收回恢复初始车头；平移1:1，仍以启动朝向为固定平移参考，不随杆的转向改变前后左右。
角度连续展开，跨±180°和多圈不反向。位置不增加低通；角速度只用40ms源时间估计和前馈，配合角度纠偏。
角参考限速、50cm缓冲及20cm附加裕量不变。新模式按跟踪误差/角度跳变/无进展保护，而不是删除保护后继续套固定车头11.5°门限。

保持XY 0.70m/s、0.80m/s²，围栏仍为最新已确认的前0.5/后1.5/左0.5/右0.4米，不恢复早期3×3米。
角速度/角加速度扫描只存在于软件对象，不能作为实机授权或硬件配置序列化。每次会话仍需准备、全新人工使能，120秒和单次会话上限不变；停止/故障/输入恢复不会自动续跑。

底盘轮心半距沿用固件近似值61mm/85mm，轮半径30mm；车体外廓半长95mm/半宽105mm不能当作轮心几何。
合成XY＋旋转先共同缩放至每轮400RPM，再用单个有效车体加速度约束插值；不逐轮硬截断，不堆叠第二个正常加速斜坡。
这只验证运动学与控制逻辑，不包括电流、温升、摩擦、轮子反转中性等待或真实制动能力。

`prepare.py --output 全新目录`运行离线回归、参数对照、原输入哈希核对，并保存软件模型曲线/指标。
只有所有用例通过才推荐软件参数；快速挑战若跟不上会单列，不隐去失败或用停车后的误差充数。
下一步为真实Sign→软件车，仍须继续保持实车断电；本目录尚不启动该实时验收。

末级门在本次纯仿真中独立使用同一组带时间戳输入重建角目标，拒绝角目标缓慢偏离操作者意图，而不只是检查限速。
后续迁移到真实ROS节点时，必须传递并绑定监督器所选的源帧身份；不能拿各节点不同时间的“最新帧”冒充已完成同帧校验。
场景中的`passed`只表示无意外保护触发、约束未越界；`tracking_meets_normal_threshold`另行标注跟踪性能，快速挑战不达标不会被隐去。
