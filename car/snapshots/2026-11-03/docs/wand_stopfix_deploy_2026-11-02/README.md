# STOPFIX_V1：独立实机浏览器入口迁移

这一步只准备主机侧软件，不再次刷写、不复位/运行STM32、不连接真实MC-Link、不启动小车，也不更改网络。STM32的刷写与完整读回事实见 `/home/PRIMARY_USER/vicon_mecanum_ws/docs/wand_stopfix_2026-11-02/DEPLOYMENT_2026-11-02.json`。原入口、原矩形和离线封存快照保持原样。

## 已封存结果

离线回归通过并封存于 [QUALIFICATION.json](prepared_v1/QUALIFICATION.json)：47项保留策略测试＋18项新准入测试、24项DOM/VM界面检查、6种入口参数冲突、8秒精确C代理失能探针、6个ROS链路场景、11个浏览器协议场景，以及诊断流不能续命运动权限的检查。正常协议场景ACTIVE 60.017秒后确认停车；真实准入构造器在禁止socket和子进程的测试环境中通过。

当前只代表实机入口的软件准备完成，`live_handshake_verified:false`、`new_revision_physical_trial_passed:false`。没有执行600秒物理演示。四项原离线阻断测试在新阶段被相应的实机准入测试替代，三项固件文件检查仍指向已部署固件原封存目录；初次测试适配错误的失败记录保留。最终封存前还补齐了检查/启动模式互斥，重跑65项测试并单独验证6种冲突组合，未改变任何控制、ROS或Node运行部件。

## 新入口的准入条件

- 必须是STOPFIX_V1的固定部署记录及其哈希，而不是只看同为4WSC/v8的协议标签。
- 重新验证两份完整1MiB刷前备份、新镜像、完整刷后读回、FF填充、应用区之外的Flash、选项字节、芯片UID、ST-Link及烧录日志；内容改变即拒绝。
- 新主机采用独立ROS命名空间 `/wand_stopfix_stage6_long600` 和独立签名范围；旧签名、旧同意字串、旧配置不能直接准入。
- 控制、末级门、签名新鲜度、浏览器焦点/输入证据、停止确认和故障锁存逻辑不放宽。运动参数仍为0.70m/s、2.00m/s²、2.00rad/s、12.00rad/s²；直接1:1平移＋相对旋转、Z不映射、无固定围栏、最长600秒。
- 旧版60秒实车记录只保留为历史观察，结合新旧正常控制等价性的离线证据解释迁移依据，不能冒充STOPFIX版本的实车性能/停车/电气验收。新记录明确 `new_revision_physical_qualified:false`。

文件凭据能核验已保存的烧录事实，但线上的4WSC/v8没有镜像哈希证明。若此后再次刷写、更换板卡或改线，必须重新取得对应的备份/读回和现场确认，不能继续复用旧凭据。

## 分阶段使用

### 1. 仅检查文件

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_stopfix.sh --check
```

默认不带参数也是文件检查，不启动ROS、浏览器或任何实车通信。完整回归成功后，结果封存于 `prepared_v1/QUALIFICATION.json`；文件不存在或主机清单尚未通过时不得视为已准备完成。

### 2. 后续经现场确认的失能零速检查

保持电池断开后拔ST-Link、恢复原接线/接回Tenda；只有得到新的现场确认后才上电。此阶段不需要Sign动作，不打开跟随页面。

```bash
bash /home/PRIMARY_USER/vicon_mecanum_ws/tools/start_car_stopfix.sh --idle-only --confirm-disabled-zero-now
```

只运行8秒，TX白名单仅允许HELLO和失能三轴零速，不提供选档、使能、清故障、启动或非零速度API。保留原300ms反馈/时钟及命令进度检查。失败即结束并保留故障，不自动重启、清故障或更改Tenda；真实结果保存于 `prepared_v1/LATEST_IDLE.json`。离线C代理的通过记录不能代替这个现场检查。

### 3. 之后才安排未开始运动的浏览器

需要新的场地、接线、定位及立即断电条件确认，再使用明确的硬件试运行入口。入口每次先运行失能零速检查，失败不开页面；成功后才启动经过来源核验的只读Vicon接收和独立ROS链路，等待浏览器新的人工单击空格。历史现场确认不会自动使能。此轮没有执行这个阶段，也没有批准新的运动。

界面仍是单击空格开始、再次空格/Esc/停止按钮结束；松键不停车，失焦/页面隐藏/失联仍终止，不自动恢复。软件就绪与已完成真实600秒演示是不同结论。

## 验证范围

测试运行限定为独立域196、专用127.0.0.1端口、新固件精确C代理，不启动真实Vicon，也不占用真实46001端口。保留策略测试与新增准入测试分开计数。实际ROS/UDP链路、浏览器协议客户端、DOM/VM界面逻辑测试均属于软件验证，不等于实际浏览器/操作系统焦点验收或物理电机性能验证。

原离线候选保持三处硬件阻断；这个新入口仅在离线验证完成、哈希证据完整且收到相应的当前现场声明时准入指定阶段。不会因新固件已刷写就自动执行未使能检查或运动。
