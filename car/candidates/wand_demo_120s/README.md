# 120秒 / 原起点双向区域独立候选

本轮确认是四个方向的最大距离，不是顺序路线：以原起点及原朝向为准，
车中心前向[-1.5,0.5]m、左向[-0.4,0.5]m，即2.0×0.9m。
各边另有0.50m物理缓冲，仍保留车身轮廓及额外0.20m硬停余量。
这是向后、向右扩展的已确认子区域，不是整个Vicon覆盖区，面积也不大于旧3×3m。

保留1:1 XY、0.70m/s、0.80m/s²；Sign高度/转角不映射车运动。
120秒从健康的第一次按住空格使能捕获原点时开始，不从打开窗口或准备时开始。
监督器、独立末级门均限时；固件150秒硬上限不改。松键、失焦、遮挡、
翻转、通信/来源异常仍停车；每进程一次，不自动恢复，不自动清故障。

从oneclick_v2复制到独立runtime，保留姿态质量诊断。旧基线、原矩形、
原`小车`命令、ESP32、STM32和Tenda不改；新入口为`小车120`。
`小车120 --check`只校验文件和旧完整读回记录；`小车120 --preview`只预览启动页。
默认打开启动页仍不运动；必须逐项确认当次场地、定位和立即断电条件，再准备/按住使能。

Vicon car01的偶发翻转并未被软件修复；预检通过不保证运行中不翻转。
120秒运行、电流、温升和停车距离均未实车验收，不能因旧20秒测试正常就标为合格。
本轮仅离线准备；不刷写、不启动实车、不自动采集Vicon覆盖范围。
